# AIProxy v0.1.21

## 更新内容

- 修复规则编辑、Map Local 导航和断点规则保存中的未保存草稿丢失问题，并让保存失败原因在编辑对话框内清晰可见。
- 修复会话清空、删除与实时更新之间的竞态，避免已删除会话被晚到事件重新恢复。
- 增强 WebSocket、HTTP/2 上游连接和代理生命周期处理，降低连接卡死、帧丢失和连接池竞态风险。

## What's new

- Fixed unsaved-draft loss in rule editing, Map Local navigation, and breakpoint-rule saving, with save failures now visible inside the editor dialog.
- Fixed races between session clearing, deletion, and live updates so deleted sessions are not resurrected by late events.
- Hardened WebSocket, HTTP/2 upstream connections, and proxy lifecycles to reduce hangs, frame loss, and connection-pool races.
