# AIProxy v0.1.7

## 更新内容

- 全面升级软件更新体验：支持启动时检查更新、活动栏更新提示和独立更新弹窗。
- 补充安装进度、检查失败状态和中英文更新说明，方便用户完成更新。

## What's new

- Redesigned the software-update experience with startup checks, an activity-bar indicator, and a dedicated update dialog.
- Added installation progress, check-failure states, and bilingual release notes to make updates easier to complete.

## 安装与更新

- Windows：下载 `.msi` 或 `.exe` 安装包。
- macOS：下载 `.dmg` 安装包。
- Linux：下载 `.AppImage`、`.deb` 或 `.rpm` 安装包。
- 该版本提供应用内更新资产；可在 **设置 → 软件更新** 中检查更新。如当前平台检查不到更新，请手动下载安装包。
- macOS 安装包未签名。若浏览器下载后显示“已损坏”，将应用移至“应用程序”目录后执行 `xattr -cr /Applications/AIProxy.app`。
- Windows 安装包未签名，首次运行时可能出现 SmartScreen 提示；请确认下载来源为本 Release 页面。

---

## Install and update

- Windows: download the `.msi` or `.exe` installer.
- macOS: download the `.dmg` installer.
- Linux: download the `.AppImage`, `.deb`, or `.rpm` package.
- Updater artifacts are available for this release. Check **Settings → Software Updates**; if your platform does not find an update, download and install the package manually.
- The macOS package is unsigned. If macOS says the browser-downloaded app is damaged, move it to Applications and run `xattr -cr /Applications/AIProxy.app`.
- The Windows package is unsigned. SmartScreen may appear on first launch; verify that you downloaded it from this Release page.
