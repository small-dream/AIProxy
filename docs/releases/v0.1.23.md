# AIProxy v0.1.23

## 更新内容

- HTTP/1.1 上游连接现在支持连接池复用和并发扩容，减少高频请求的连接建立开销，并避免慢请求阻塞同一目标的其他请求。
- 改进连接异常、超时和取消时的回收，降低上游连接泄漏和后续请求失败的风险。

## What's new

- HTTP/1.1 upstream connections now support pooling and bounded concurrent expansion, reducing connection setup overhead for high-frequency traffic and preventing slow requests from blocking other requests to the same origin.
- Improved cleanup for upstream connection errors, timeouts, and cancellations to reduce connection leaks and follow-up request failures.
