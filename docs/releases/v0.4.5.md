# AIProxy v0.4.5

## 更新内容

- 清空大量会话时界面恢复更快：数据库记录立即清空，消息体文件在后台释放，不再需要等待成千上万个文件逐个删除。
- 如果后台释放未完成或应用退出，下次启动会自动继续清理残留的临时目录；当系统仍占用文件时（例如 Windows），清空会回退到稳妥的同步删除并在失败时明确提示，不会出现“界面已清空但重启后会话复活”。
- 升级多个底层依赖，修复已公开的安全问题，提升抓包与 MCP 相关能力的可靠性。

## What's new

- Clearing a large session history now recovers the UI much faster: database rows are removed immediately while body files are reclaimed in the background instead of waiting for thousands of per-file deletions.
- If background cleanup is interrupted or the app exits, the next launch resumes cleanup of the leftover temporary directory. If the OS still holds files open (for example on Windows), the clear falls back to a safe synchronous delete and reports a clear error instead of silently recreating sessions after a restart.
- Updated several underlying dependencies to address published security issues, improving the reliability of capture and MCP features.
