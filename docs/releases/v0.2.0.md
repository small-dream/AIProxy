# AIProxy v0.2.0

## 更新内容

- Agent Access 升级为受控自动化：在用户授权后，AI Agent 可完成工作区与 SSL 配置、证书生成与安装引导、抓包启停、系统代理切换和 Session 清理。
- 新增 `get_app_status`，Agent 可以一次获取应用、控制通道、抓包、证书、工作区和系统代理状态，并在需要用户操作时给出明确下一步。
- 控制权限默认全部关闭，可在连接时选择“只读”或“完整控制”，连接后仍可按抓包、系统代理、证书和 Session 删除四项能力独立调整。
- 控制操作通过仅当前用户可访问的本地通道执行并写入审计；应用未运行时会自动拉起并聚焦，所有 Agent 动作都会在应用内显示提示。
- Session 清空与批量删除现在返回准确删除数量，并同时清理数据库与 Body 数据；已有只读工具的现有用法保持兼容。

## What's new

- Agent Access now supports permission-gated automation, letting an AI agent configure workspaces and SSL, guide certificate generation and installation, start or stop capture, switch the system proxy, and clean sessions after the user grants access.
- A new `get_app_status` tool reports app, control channel, capture, certificate, workspace, and system proxy state together, including a clear next step when user action is required.
- Control permissions are off by default. Choose **Read-only** or **Full control** when connecting, then fine-tune capture, system proxy, certificate, and session deletion access independently.
- Control actions run over an owner-only local channel and are audited. AIProxy launches and focuses automatically when needed, and shows an in-app notice for every agent action.
- Clearing and batch-deleting sessions now return accurate counts and remove both database and body data; existing read-only tool usage remains compatible.
