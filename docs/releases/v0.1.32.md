# AIProxy v0.1.32

## 更新内容

- 会话列表的批量删除和"清除其他会话"现在会真正从存储中删除：进行中的会话不会再"复活"，重启后已删除的会话也不会再出现。
- WebSocket 连接状态指示现在真实反映连接状态：连接关闭后，消息面板会立即显示已关闭，不再一直显示活跃。
- Map 规则失效（如映射的本地文件被移动或删除）时，请求会继续按原样转发并在会话详情中记录失败原因，不再直接断开连接。
- 系统代理设置失败时现在会弹出警告提示，避免代理未生效却毫无感知。
- 会话详情中"经上游代理"指示现在正确显示。
- 环境变量编辑器修复：保存后正在输入的内容不再被覆盖，关闭对话框前的编辑不会再丢失。
- 节流规则的默认规则名、副本后缀等文案现在支持中英文显示。
- 提升高负载下的稳定性：WebSocket 长连接纳入连接数管控，连接耗尽时明确返回错误；端口资源紧张时代理不再空转占用 CPU。
- 修复 Windows 上超大请求/响应体无法查看的问题，以及 Linux 上移除根证书后仍被系统信任的问题。

## What's new

- Batch delete and "Clear other sessions" now actually remove sessions from storage: in-flight sessions no longer reappear, and deleted sessions stay gone after restart.
- The WebSocket connection indicator now reflects real connection state: once a connection closes, the messages panel shows it as closed instead of staying active.
- When a Map rule fails (e.g. its mapped local file was moved or deleted), the request keeps forwarding unchanged and the failure is recorded in the session detail, instead of resetting the connection.
- A warning notification now appears when applying the system proxy fails, so a silently inactive proxy is no longer possible.
- The "via upstream proxy" indicator in session details now displays correctly.
- Environment variable editor fixes: saving no longer overwrites text you are still typing, and edits made right before closing the dialog are no longer lost.
- Default throttle rule names, copy suffixes, and related labels are now localized in English and Chinese.
- Improved stability under load: long-lived WebSocket connections now count toward the connection limit with a clear error when exhausted, and the proxy no longer spins at full CPU when running out of file descriptors.
- Fixed viewing very large request/response bodies on Windows, and an issue on Linux where a removed root certificate remained trusted by the system.
