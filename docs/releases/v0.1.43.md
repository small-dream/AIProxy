# AIProxy v0.1.43

## 更新内容

- 新增本地 Agent 接入：Codex、Claude Code、Cursor 可以通过 MCP 直接查询已抓取的 HTTP / WebSocket 会话，让 AI 基于真实流量完成搜索、对比和分析，无需导出数据或手工转述。
- 新增一键写入 MCP 配置：在「设置 > Agent 接入」中按客户端直接写入配置；覆盖已有文件前会自动备份，不再需要复制粘贴或手工编辑 `config.toml` / `mcp.json`。
- 新增一键安装 AIProxy Agent Skill，让客户端按“先搜索、再读详情、最后按需取 Body”的顺序使用这些工具。
- 隐私默认更保守：默认脱敏、只读访问、Body 分块读取；权限可逐项控制，并记录仅含元数据的审计日志。

## What's new

- Local Agent access: Codex, Claude Code, and Cursor can query captured HTTP / WebSocket sessions through MCP, letting AI search, compare, and analyze real traffic without exporting data or manually retelling it.
- One-click MCP setup: write each client's configuration directly from Settings > Agent Access. Existing files are backed up before changes, so there is no need to copy snippets or edit `config.toml` / `mcp.json` by hand.
- One-click AIProxy Agent Skill installation teaches each client to search first, inspect details second, and fetch only the body fragments it needs.
- Privacy stays conservative by default: redaction, read-only access, bounded body reads, per-permission controls, and a metadata-only audit log.
