# AIProxy v0.2.6

## 更新内容

- 抓包会话的 Host 右键菜单新增 **复制 Host URL**，可直接复制协议、Host 与显式端口，便于快速复用地址或排查接口，且不会带上请求路径与查询参数。

## What's new

- The host context menu for captured sessions now includes **Copy Host URL**. It copies the protocol, host, and explicit port for quick reuse or debugging, without the request path or query string.
