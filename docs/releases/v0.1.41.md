# AIProxy v0.1.41

## 更新内容

- 修复：请求详情的「时序」分组里，DNS、连接、TLS 握手三行不再自相矛盾——复用连接池里的连接时统一显示「复用连接」，不再出现「<1 ms」和「不可用」两种说法。
- 修复：代理抓包看不到「请求写完」这一时刻，之前「请求」「请求结束时间」「请求速度」三行对每条会话都恒显示「不可用」，现已移除；只有真正采集到该阶段的数据（如 HAR 导入）才会出现这三行。
- 改进：mock、Map Local、脚本改写等没有出网请求的会话，连接类阶段显示「不适用」，不再报「不可用」。
- 改进：时序色带不再为 0 毫秒的阶段绘制色块，避免被误读成「该阶段花掉了时间」。

## What's new

- Fixed: DNS, Connect, and TLS Handshake in the Timing group no longer contradict each other — a pooled connection reports "Connection reused" instead of "<1 ms" for some rows and "Unavailable" for others.
- Fixed: the proxy cannot observe when a request finished being written, so the Request, Request End Time, and Request Speed rows used to read "Unavailable" on every session; they are gone now and only appear when the phase was actually captured (for example HAR imports).
- Improved: sessions that never reached the network (mock, Map Local, script overrides) report "N/A" for connection phases instead of "Unavailable".
- Improved: the timing band no longer draws a sliver for 0 ms phases, which used to read as a phase that took time.
