# AIProxy v0.1.50

## 更新内容

- SSL 代理默认排除项更精准：不再默认排除 Google API、Google 静态资源与 Google 用户内容域名，相关 HTTPS 流量可正常解密查看，同时保留 Google Play、Google 账号、iCloud、Apple 与 TikTok/ByteDance 等建议排除项。
- 修复不完整或异常的 SSL 代理设置可能意外关闭排除保护的问题；缺少排除开关时默认保持启用，缺少排除列表时回退到推荐列表。
- 「恢复推荐列表」现在会保留自定义排除项，只补充缺失的推荐项并重新启用已有推荐项，不再覆盖用户的个性化配置。
- 右键将请求加入 Include 白名单时，如果目标域名命中已启用的 Exclude 列表，会明确提示冲突并中止操作，避免白名单与实际解密行为不一致。
- SSL 代理设置页新增当前实际生效的模式摘要，可快速确认是「仅白名单」「除排除外全部」还是「排除已关闭，全部解密」。

## What's new

- SSL Proxying now ships with more precise default exclusions. Google API, Google static assets, and Google user-content domains are no longer excluded by default, while recommended exclusions for Google Play, Google accounts, iCloud, Apple, and TikTok/ByteDance remain.
- Incomplete or malformed SSL Proxying settings can no longer silently disable exclusion protection. Missing enablement falls back to enabled, and a missing list falls back to the recommended exclusions.
- "Restore recommended list" now preserves custom exclusions and only adds missing recommendations or re-enables existing ones instead of replacing your configuration.
- Adding a request to the Include list from the context menu now detects a conflict with an enabled Exclude entry, explains it, and stops the action so the whitelist cannot silently disagree with actual decryption.
- The SSL Proxying settings now show the effective mode at a glance: includes only, all except exclusions, or exclusions disabled with everything decrypted.
