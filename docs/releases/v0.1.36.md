# AIProxy v0.1.36

## 更新内容

- 修复：写操作失败后，错误提示会一直挂在编辑器里，即使切换到另一条规则也还在显示上一条规则的失败信息；现在切换到其他规则会清除这条过期提示，而新出现的失败仍会照常显示。
- 参数：规则列表底部的重排提示在 macOS 上显示为 ⌥↑/↓（Option），不再显示 Alt，与键盘上的实际按键一致。
- 无障碍：Map / DNS / Scripts / Breakpoint 编辑器的“匹配类型”下拉补上了可读标签，读屏软件现在能朗读控件名称，而不只是读出当前选中值。

## What's new

- Fixed: after a failed write, the editor kept the error visible even after switching to another rule, so the message described the previous rule. Moving to another rule now clears the stale alert, while a fresh failure still shows up as before.
- The reorder hint under a rule list now shows ⌥↑/↓ on macOS instead of Alt, matching the keys on the keyboard.
- Accessibility: the match-type dropdown in the Map / DNS / Scripts / Breakpoint editors now carries a readable label, so screen readers announce the control by name instead of only reading the selected value.
