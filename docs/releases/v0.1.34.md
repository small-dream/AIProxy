# AIProxy v0.1.34

## 更新内容

- 优化 SSL 代理设置的开关状态：包含列表 / 排除列表的总开关关闭时，列表内的域名开关会同步置灰禁用，并提示「条目会保留，但当前不生效」。此前总开关已关闭、条目开关却仍显示为开启，容易被误认为这些规则仍在生效。

## What's new

- Clearer switches in SSL Proxying settings: when the Include or Exclude master switch is off, the per-host switches underneath are now greyed out and disabled, with a note that the entries are kept but not applied. Previously they still looked switched on, which suggested those rules were active.
