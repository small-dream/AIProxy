# AIProxy v0.4.1

## 更新内容

- 修复 Agent 接入「读取权限」中权限预设说明与下拉框混排的问题；预设说明现在位于左侧，选项框右对齐，窄窗口下自动纵向排列，阅读和操作更清晰。
- 没有可恢复的自定义组合时不再显示灰色“自定义”项；产生自定义组合后该选项会自动出现。

## What's new

- Fixed the Agent Access **Read permissions** layout where the permission preset description and dropdown overlapped. The description now sits on the left, the selector is right-aligned, and both stack cleanly in narrow windows.
- **Custom** is no longer shown as a disabled option when there is no custom combination to restore. It appears automatically after a custom combination exists.
