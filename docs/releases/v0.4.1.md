# AIProxy v0.4.1

## 更新内容

- Agent 接入的权限预设精简为 **只读分析（默认值）**、**完全控制** 和 **自定义**，三项始终可选，不再出现灰色的不可选项。
- 首次选择“自定义”会复制“只读分析”；之后再选“自定义”会恢复本次编辑中最近一次自定义组合。
- “完全控制”只开启本版全部可用能力，保存时仍会要求高风险权限确认。
- 修复权限预设说明与下拉框混排的问题；说明现在位于左侧，选项框右对齐，窄窗口下自动纵向排列。

## What's new

- Agent Access now offers three permission presets: **Read-only analysis (default)**, **Full control**, and **Custom**. All three are always selectable, with no disabled gray option.
- The first **Custom** selection copies **Read-only analysis**; selecting it again later restores the latest custom combination from the current editing session.
- **Full control** enables every capability available in this release, while saving still requires the high-risk confirmation.
- Fixed the **Read permissions** layout where the preset description and dropdown overlapped. The description now sits on the left, the selector is right-aligned, and both stack cleanly in narrow windows.
