# AIProxy v0.4.3

## 更新内容

- Agent 接入：连接前对“完全控制”或草稿中的高风险权限增加二次确认；“只读分析”重连会保留已有“请求时询问”策略，不再静默改为“禁止”。
- Agent 接入：审批卡支持“关闭”，授权列表显示最近结束或“结果未知”的授权，并在结果未知时提示不要盲目重试。
- 自动化实验：应用与回滚会校验 workspace 与生命周期；重复应用、发布失败重试与回滚后的幂等重放返回真实状态；验证与回滚串行，避免旧证据绑定到新运行时；TTL 清理失败会写入日志。
- Map Local：请求路径被限制在映射根目录内，阻断 Windows 盘符前缀导致的目录外文件读取。
- Rewrite Body Fields：只替换实际修改的字段值，保留其余数字字面量、转义与空白，降低签名接口被整体重写破坏的风险。
- 断点 Drop：请求或响应被丢弃时，会话记录显示失败状态，不再保留客户端实际未收到的上游响应。
- MCP：脱敏对比不再返回原始 Body 摘要；文本回退能识别转义敏感键；空白 `textQuery` 会报错；自动化工具的审计记录不再重复。
- 桌面端：Windows 应用内更新改为静默安装并由安装器重启；顶栏代理控制细节优化。

## What's new

- Agent Access: connecting with Full control (or unsaved high-risk draft permissions) now requires a separate confirmation; reconnecting with Read-only analysis keeps existing "ask when requested" policies instead of silently disabling them.
- Agent Access: the approval card can be dismissed, and the grant list now shows recently finished or "result unknown" grants with a warning not to retry blindly.
- Automation experiments: apply and rollback validate workspace and lifecycle scope; retries and idempotent replays return the real state; verification is serialized with rollback so stale evidence cannot be attached to a new runtime; TTL cleanup failures are logged.
- Map Local: request paths are confined to the mapped root, blocking Windows drive-prefix reads outside the directory.
- Rewrite Body Fields: only the changed field values are patched, preserving other number literals, escapes, and whitespace so signature-sensitive payloads are not rewritten wholesale.
- Breakpoint drops: a dropped request or response is recorded as a failed session instead of keeping an upstream response the client never received.
- MCP: redacted comparisons no longer expose a raw body digest; the text fallback recognizes escaped sensitive keys; blank `textQuery` is rejected; automation tools no longer duplicate audit entries.
- Desktop: Windows in-app updates install quietly and the installer relaunches the app; top-bar proxy controls were refined.
