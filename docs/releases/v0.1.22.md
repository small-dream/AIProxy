# AIProxy v0.1.22

## 更新内容

- 强化 multipart 附件安全：附件发送改用后端短生命周期 token，避免渲染层伪造文件路径。
- 附件支持短时间内重试、Collection 重放和应用重启后的恢复，并在发送时重新校验文件位置。
- 统一代理连接、WebSocket、响应体和上游代理等超时策略，提升异常连接的可控性。

## What's new

- Hardened multipart attachment security with short-lived backend-issued tokens, preventing renderer-forged file paths.
- Attachments can be retried, replayed from Collections, and recovered across app restarts during the token lifetime, with send-time path validation.
- Centralized proxy, WebSocket, response-body, and upstream-proxy timeout policies for more predictable failure handling.
