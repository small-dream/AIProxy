# AIProxy v0.1.26

## 更新内容

- SSL 代理设置升级：包含 / 排除列表各新增总开关，每条域名规则带独立开关。想看某个域名就打开「只看包含列表」并启用对应条目，想看全部就关掉它——不再需要反复删除、重加规则。
- 保留但未启用的规则不影响抓包，随时可以恢复，方便在不同抓包范围之间快速切换。

## What's new

- SSL Proxying settings are now more flexible: each of the Include / Exclude lists has a master switch, and every rule has its own on/off switch. Focus on a single domain by enabling the Include list with just that entry, or decrypt everything by flipping it off — no more deleting and re-adding rules.
- Disabled rules stay in the list without affecting capture and can be re-enabled at any time, making it easy to switch between different capture scopes.
