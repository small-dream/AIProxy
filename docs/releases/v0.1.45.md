# AIProxy v0.1.45

## 更新内容

- 重新整理「设置 > Agent 接入」：客户端连接移到首屏，服务状态更紧凑，权限、诊断和审计信息按使用频率分层展示。
- 客户端连接升级为一键完成 MCP 配置与 Skill 安装，统一显示「已连接 / 需要更新 / 未连接」，并明确提示配置成功但 Skill 未完成等部分成功状态。
- 权限修改新增「未保存」提示与保存 / 放弃操作；未脱敏权限和审计日志默认折叠，长路径改为单行展示并支持复制。

## What's new

- Reworked Settings > Agent Access so client connections appear first, service status is more compact, and permissions, diagnostics, and audit details are organized by frequency of use.
- Client setup now completes MCP configuration and Skill installation in one connection flow, with consistent Connected / Needs update / Not connected states and clear feedback when only part of the setup succeeds.
- Permission edits now show an explicit unsaved state with Save and Discard actions. Unredacted access and the audit log are collapsed by default, and long paths stay on one line with copy support.
