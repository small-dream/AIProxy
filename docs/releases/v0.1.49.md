# AIProxy v0.1.49

## 更新内容

- MCP 新增 POST 表单参数提取：`get_session_body` 现在可以直接返回 `application/x-www-form-urlencoded` 与 `multipart/form-data` 请求的参数，可按参数名只取需要的字段，也可以一次列出全部参数。
- 文件上传字段只返回文件名、类型和大小，不返回文件内容；表单参数与 Query、JSON 字段一样默认脱敏，敏感值不会以原文出现在 Agent 对话中。
- 返回值新增参数总数与显式截断标记（`formParamCount`、`formParamsTruncated`），大表单不会被静默截断。
- 内置 Agent Skill 升级到 2.3，Agent 会优先使用新能力读取表单参数；已安装旧 Skill 的客户端会提示更新。

## What's new

- MCP now extracts POST form parameters: `get_session_body` returns fields from `application/x-www-form-urlencoded` and `multipart/form-data` requests, either as a named subset or as the full parameter list.
- File upload fields return only the file name, content type, and size, never the file content. Form values are redacted by default, just like query parameters and JSON fields.
- Results now report the total parameter count and explicit truncation flags (`formParamCount`, `formParamsTruncated`), so large forms are never clipped silently.
- The bundled Agent Skill is now 2.3 and prefers the new form extraction; clients with an older Skill are prompted to update.
