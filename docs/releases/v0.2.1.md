# AIProxy v0.2.1

## 更新内容

- Agent 可通过新的只读工具 `diagnose_ai_proxy_issue` 排查 AIProxy 自身的设置、证书、抓包、系统代理、Agent 接入与控制通道故障，并直接获得可能原因和按序解决步骤。
- 诊断会结合应用状态、受限的脱敏日志摘要与最近 Agent 审计错误；日志不可读或控制通道不可用时明确标注证据范围，不会把缺失的证据描述成已读取完整日志。
- 日志访问仅限 AIProxy 白名单滚动日志与元数据审计，默认只读取 WARN/ERROR、限制返回行数与大小，并对内容再次脱敏。此前的读取、受控操作与权限配置保持兼容。

## What's new

- A new read-only `diagnose_ai_proxy_issue` tool helps Agents troubleshoot AIProxy setup, certificate, capture, system proxy, Agent Access, and control-channel failures with likely causes and ordered fixes.
- Diagnostics combine live app status, a bounded summary of redacted logs, and recent metadata-only Agent audit errors. When logs or the control channel are unavailable, the tool clearly reports the evidence scope instead of presenting missing evidence as a complete log.
- Log access is limited to AIProxy's allowlisted rolling logs and metadata audit, returns WARN/ERROR by default, caps line count and size, and applies redaction again. Existing read tools, gated controls, and permission settings remain compatible.
