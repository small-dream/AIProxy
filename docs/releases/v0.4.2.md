# AIProxy v0.4.2

## 更新内容

- MCP 关键字搜索（`textQuery`）的扫描上限从 8 MiB 提升到 16 MiB，可覆盖更大的响应体。
- 大型 JSON Body 改为流式脱敏与分块搜索，降低搜索时的内存占用。
- 超过搜索上限时，错误会明确提示 AI 工具改用 `jsonPaths` 读取目标字段，避免继续分页完整 Body。

## What's new

- The MCP text search limit (`textQuery`) is now 16 MiB instead of 8 MiB, covering larger response bodies.
- Large JSON bodies use streaming redaction and chunked matching to reduce memory usage during search.
- When a body exceeds the limit, the error now directs AI tools to read the target fields with `jsonPaths` instead of paging the full body.
