# AIProxy v0.1.29

## 更新内容

- Host 分组右键菜单新增「加入包含列表」：一键把域名加入 SSL 解密白名单，仅解密匹配域名，代理运行时自动重启生效；「停用 / 启用 SSL 解密」同步迁移到 Host 右键菜单，按域名快速控制。
- 优化设置中的 SSL 代理界面：include / exclude 列表的总开关内联到各自标题行，列表限定高度内滚动，两个列表在空态与滚动条宽度上保持一致。
- 更新入口改为蓝色文本按钮，与顶栏其余操作对齐。

## What's new

- Right-click a host group to "Add to Include list": put a domain on the SSL decryption allowlist in one click (only matching hosts are decrypted) and it takes effect with an automatic proxy restart; "Disable / Enable SSL Decryption" now lives on the same host menu for per-domain control.
- Reworked the SSL Proxying settings: each list's master switch sits inline in its header, lists scroll within a bounded height, and the Include / Exclude lists now render identically whether empty or full.
- The update entry is now a blue text button, aligned with the rest of the top bar.
