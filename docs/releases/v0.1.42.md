# AIProxy v0.1.42

## 更新内容

- 修复：同一个主机的并发请求，「时序」里的各阶段不再对不上总时长——新增「连接等待」一行与一段同色色带，显示请求在上游连接池里排队等连接就绪的时间（等另一条同主机请求正在建立的连接，或等连接被释放）。这段时间以前完全没有表达，会话会出现「总时长 2030 ms、延迟 1398 ms」而其余几百毫秒无处可查的情况。
- 改进：该行只在请求真的排过队（连接等待大于 0）时出现；没有排队的会话界面与之前完全一致。

## What's new

- Fixed: concurrent requests to the same host no longer leave a gap in the Timing group — a new "Connection wait" row and segment report how long a request queued in the upstream connection pool waiting for the connection to become ready (while another request to the same host dialed, or while a connection was released). That time used to be invisible, so a session could read "2030 ms total, 1398 ms latency" with hundreds of milliseconds unaccounted for.
- Improved: the row only appears when the request actually queued (connection wait above 0); sessions that never queued look exactly as before.
