# AIProxy v0.1.25

## 更新内容

- 修复 WebSocket 会话中超大消息的处理：超过大小上限的消息现在会被标记为「已截断」并如实显示，不再作为异常数据丢失。
- 提升上游连接可靠性：当域名解析出多个 IP 时依次尝试连接，单个地址不可达不再直接导致整次请求失败。
- 复制请求、响应或 cURL 命令失败时（如剪贴板被占用、会话数据加载失败），现在会给出「复制失败」提示，不再静默无响应。
- 修复清空全部会话时数据库清理失败仍会删除文件的问题，避免残留会话出现悬空引用。
- 请求/响应体大小统计改为按字节计算，含中文等多字节内容时显示更准确。
- 修复自动更新「安装中」状态可能卡住的问题，更新安装流程更稳定。

## What's new

- Fixed handling of oversized WebSocket messages: messages exceeding the size limit are now flagged as truncated and shown honestly, instead of being dropped as corrupt data.
- Improved upstream connectivity: when a hostname resolves to multiple IPs, each address is tried in turn, so one unreachable address no longer fails the whole request.
- Copying a request, response, or cURL command now shows a "Copy failed" notice when the clipboard write or session-data loading fails, instead of doing nothing.
- Fixed "clear all sessions" deleting body files when the database clear fails, which left surviving sessions with dangling references.
- Request/response body sizes are now measured in bytes, so multi-byte content such as Chinese text displays more accurately.
- Fixed the auto-update "Installing" state getting stuck; update installs are now more reliable.
