# AIProxy v0.1.38

## 更新内容

- 修复：在代码块（JSON 文本 / Raw / Text Body）里选中文字后右键，菜单一弹出选中高亮就消失，看不到自己将要复制的内容；现在菜单打开期间由视图自己绘制高亮（颜色与系统选中完全相同），菜单关闭后再交还给系统。
- 改进：关闭代码块的右键菜单不再丢掉选区——执行复制、`Search` 或按 Esc 之后文字仍处于选中状态，`Cmd/Ctrl+C` 继续可用；只有点击菜单外才按系统习惯清空选区。
- 改进：没有选中文字时右键，会高亮指针所指的字段，让 `Copy Key` / `Copy Value` / `Copy Path` 的作用对象一目了然。

## What's new

- Fixed: right-clicking a selection in a code block (JSON Text / Raw / Text Body) used to clear the highlight the moment the menu appeared, so you could no longer see what you were about to copy. The view now paints the highlight itself while the menu is open — in exactly the same colour as the system selection — and hands it back to the system once the menu closes.
- Improved: closing that menu no longer drops the selection — after Copy, Search or Escape the text stays selected and `Cmd/Ctrl+C` keeps working; only a click outside clears it, matching the platform behaviour.
- Improved: right-clicking with nothing selected highlights the field under the pointer, so `Copy Key` / `Copy Value` / `Copy Path` show what they would act on.
