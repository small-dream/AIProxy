# AIProxy v0.1.40

## 更新内容

- 改进：请求详情的「时序」分组不再用一根粗实心条展示耗时构成，改为一条细长的浅色色带，不再抢走整个概览列表的视觉焦点。
- 改进：总耗时移到「时序」分组标题右侧，与其它字段对齐在同一列；每个阶段（DNS / 连接 / TLS 握手 / 请求 / 延迟 / 响应）的字段行前都有一个同色圆点，把色带和数值直接对应起来。
- 改进：鼠标悬停在某个阶段行时，色带会高亮该阶段、其余阶段变淡；鼠标移到色带上也能看到「阶段 · 耗时 · 占比」的提示。
- 改进：阶段行的排列顺序与真实时间轴一致（DNS → 连接 → TLS 握手 → 请求 → 延迟 → 响应），并统一使用字段行的阶段名称，不再出现「等待 / 下载」与「延迟 / 响应」两套叫法。
- 修复：未采集到的阶段不再在色带上留下一小截灰色占位块。

## What's new

- Improved: the Timing group in request details no longer uses a thick solid bar to show the breakdown; it is now a slim muted band that no longer outweighs everything else in the overview.
- Improved: total duration moved next to the Timing section title and lines up with the other values, and every phase row (DNS / Connect / TLS Handshake / Request / Latency / Response) now carries a matching colour dot so the band maps straight onto the numbers.
- Improved: hovering a phase row highlights its part of the band and dims the rest, and hovering the band itself shows a "phase · duration · share" tooltip.
- Improved: phase rows follow the real timeline order (DNS → Connect → TLS Handshake → Request → Latency → Response) and reuse the field labels, so the same phase is no longer named two different ways.
- Fixed: phases that were never captured no longer leave a small grey placeholder sliver in the band.
