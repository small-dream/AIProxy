# AIProxy v0.1.47

## 更新内容

- Claude Code 接入改为用户级全局配置：一次连接后所有项目可用，与 Codex、Cursor 保持一致，不再选择项目根目录。
- 自动安全合并 `~/.claude.json` 顶层的 `mcpServers`，保留其他 Claude Code 配置，并在写入前备份原文件。
- 支持 `CLAUDE_CONFIG_DIR`：使用自定义配置目录时，MCP 配置与 AIProxy Skill 会写入对应位置。
- 已连接的 Claude Code 现在使用与其他客户端一致的状态检测和“需要更新”提示。
- 旧版本写入的项目级 `.mcp.json` 不会被自动删除；如果其中仍保留 `aiproxy` 条目，建议手动移除，避免重复配置。

## What's new

- Claude Code now uses a user-level global configuration: connect once and use it across all projects, with the same flow as Codex and Cursor and no project-root picker.
- The top-level `mcpServers` entry in `~/.claude.json` is merged safely, preserving other Claude Code settings and backing up the original file before writing.
- `CLAUDE_CONFIG_DIR` is supported, so MCP configuration and the AIProxy Skill are written to the matching custom location.
- Claude Code now uses the same connection-state detection and “Needs update” prompts as the other clients.
- Project-level `.mcp.json` files created by older versions are not removed automatically; if an `aiproxy` entry remains there, remove it manually to avoid duplicate configuration.
