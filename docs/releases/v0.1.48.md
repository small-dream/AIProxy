# AIProxy v0.1.48

## 更新内容

- Agent 接入新增连接前权限模板：可选择「仅元数据」「含响应 Body」「含原始数据」，连接后若 Body 关闭会明确提示 Agent 无法分析响应体。
- 「验证连接」会真正启动 MCP sidecar 完成握手与一次查询，逐项展示 sidecar、数据库、schema、权限与工具状态，并可复制完整诊断。
- 支持断开 Codex / Claude Code / Cursor：移除 aiproxy 配置、删除 AIProxy 安装的 Skill，修改前自动备份原文件。
- MCP 结果新增数据新鲜度：返回最新会话时间、抓包状态与状态更新时间，Agent 可以说明“数据截止 12:03”，而不是假设实时。
- Agent Skill 改为英文 canonical 正文 + 中英双语触发词，并在界面显示已安装与内置版本，旧版本会提示升级。
- 工具契约与文案修复：`get_insights` 支持 `since`，`compact` 保留 host，Body 工具的 `part` 必填说明，schema/权限错误给出可执行指引，连接状态改为「已配置 / 需更新 / 未配置」。

## What's new

- Agent Access now asks for a permission scope before connecting (metadata only, response bodies, or raw data) and warns when Body access stays off.
- "Verify connection" performs a real MCP handshake and one query, reports sidecar, database, schema, permission, and tool checks, and can copy the full diagnostics.
- Disconnect Codex, Claude Code, or Cursor: removes the aiproxy entry, deletes the AIProxy-managed Skill, and backs up the config first.
- MCP results now report data freshness: latest session time, capture status, and status update time, so the Agent can say "data ends at 12:03" instead of implying live traffic.
- The Agent Skill is English canonical with bilingual trigger words; the UI shows installed vs bundled versions and prompts an upgrade.
- Contract and copy fixes: `since` for `get_insights`, host kept in compact results, required `part` documented, actionable schema/permission errors, and configured/update/not-configured status wording.
