# AIProxy v0.3.1

## 更新内容

- 修复 Agent 限时授权在动作同时需要多个能力时，批准后仍可能失败的问题；现在缺失的每项能力会分别绑定审批，并在同一动作中正确校验。
- 修复临时授权未传递到 Agent 自动化能力的问题，并确保把权限改回禁止或立即收回控制后，已有临时授权也不能继续使用。
- 重放审批卡现在显示解析后的实际 Host、路径和最终方法；会话不存在时会直接返回错误，不再出现无法判断目标的审批。
- “读取会话元数据”不再显示无法执行的“请求时询问”，改为明确的“禁止 / 始终允许”。相关中英文帮助文档已同步更新。

## What's new

- Fixed temporary Agent approvals that could still fail after approval when one action required multiple capabilities. Each missing capability is now approved and validated independently within the same action.
- Fixed temporary approvals not reaching Agent automation capabilities. Existing grants can no longer be used after their permission is blocked or control is revoked.
- Replay approval cards now show the resolved host, path, and final method. A missing session returns an error instead of opening an approval card without a usable target.
- **Read session metadata** no longer offers the unsupported **Ask** state and now uses a clear **Blocked / Always allow** choice. The Chinese and English in-app guides are updated to match.
