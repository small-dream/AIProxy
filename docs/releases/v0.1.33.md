# AIProxy v0.1.33

## 更新内容

- 修复部分上游服务器无法连接的问题：当服务端只能以 RSA-PSS-SHA512 完成 TLS 握手签名时，代理不再把它当作不支持的签名方式而拒绝连接。
- 修复一处安全隐患：处理高度压缩的响应内容时不再可能无上限占用内存，异常响应会被安全地按原样处理，内存占用保持可控。
- 升级底层网络与 TLS 组件，修复多个已知安全漏洞，提升整体安全性。

## What's new

- Fixed connectivity with certain upstream servers: when a server can only sign the TLS handshake with RSA-PSS-SHA512, the proxy no longer rejects the connection as an unsupported signature scheme.
- Fixed a security issue where a highly compressed response could consume unbounded memory; such responses are now handled safely and memory usage stays bounded.
- Upgraded the underlying networking and TLS components, resolving several known vulnerabilities for better overall security.
