# AIProxy v0.4.7

## 更新内容

- 点「清空会话」后列表现在会立即清空。此前历史会话很多时，界面要等数据库逐行级联删除提交完成（可达数秒）才有反应；现在确认清空后界面即时响应，数据库删除仍在命令内随后完成提交，清空的持久性语义不变。
- 若清空过程中数据库删除失败，列表会根据仍然存活的会话自动恢复，不会停留在错误的空列表。

## What's new

- The session list now empties the instant you confirm a clear. Previously the UI waited for the database cascade delete to commit — up to several seconds with a large history — before reacting; the delete still commits right after within the same command, so clear durability is unchanged.
- If the database delete fails mid-clear, the list is automatically restored from the sessions that are still durable instead of showing a stale empty view.
