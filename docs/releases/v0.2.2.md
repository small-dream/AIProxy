# AIProxy v0.2.2

## 更新内容

- MCP 读取大型 JSON 响应时可按 `jsonPaths` 流式提取，只返回目标字段；目标过大时可通过受限的 `valueSummary` 继续下钻，不再为了一个字段读取整个数 MB 的 Body。
- `get_session_body` 与 `get_session_fields` 使用一致的按需提取语义，并增加单值、匹配数、字段载荷和批量扫描预算及明确的截断原因，避免无界读取和 token 浪费。
- Agent 闭环新增等待匹配会话、导出 cURL、同 host 重放与临时 Agent 规则，并补充 WebSocket 消息、结构化失败原因和失败聚合检索，便于从触发请求、等待结果到复现与验证。
- 新写能力继续受权限保护且默认关闭；cURL 导出会为敏感值使用占位符，重放直连原始上游并明确不执行 AIProxy、用户或 Agent 规则。

## What's new

- MCP can now stream `jsonPaths` extraction from large JSON responses and return only the requested fields. Oversized targets expose a bounded `valueSummary` for narrower follow-up requests instead of requiring the whole multi-megabyte body.
- `get_session_body` and `get_session_fields` now share one on-demand extraction path, with per-value, match, payload, and batch scan budgets plus explicit truncation reasons to prevent unbounded reads and token waste.
- Agent workflows add wait-for-session, cURL export, same-host replay, and temporary Agent rules, along with WebSocket messages, structured failure details, and failure aggregation for request-to-verification loops.
- New write capabilities remain permission-gated and off by default. cURL exports use placeholders for sensitive values, and replay goes directly to the original upstream host without applying AIProxy, user, or Agent rules.
