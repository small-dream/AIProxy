# AIProxy v0.1.37

## 更新内容

- 新增：JSON 文本视图现在按“字段”而不是“字符”交互——双击选中指针下的整个字段（字符串不含引号），三击选中整行，不用再跟引号和逗号对齐；按住 Option / Shift / Command 的双击仍保持系统原生选择。
- 新增：在 JSON 文本视图右键即可复制字段名、字段值或字段路径（例如 `$.store.book[0].title`），写规则或定位字段时不必手动翻找；指针位置解析不出字段时不显示这些操作。
- 新增：录制中且系统代理未开启时，状态栏的系统代理项会以警示色提示“仅抓取手动指向代理端口的流量”，避免把 Recording 误当成整机抓包。
- 新增：顶部 Start / Stop Proxy 按钮加大尺寸，录制中在旁边显示红色脉冲圆点与已录制时长（mm:ss，超过 1 小时为 h:mm:ss）。

## What's new

- New: the JSON Text view now works on fields instead of characters — double-click selects the whole field under the pointer (strings without their quotes) and triple-click selects the line, so you no longer have to line up with quotes and commas. Modified double-clicks (Option / Shift / Command) keep the native selection.
- New: right-click in the JSON Text view to copy the field name, its value, or its path (for example `$.store.book[0].title`) when writing rules; the actions stay hidden when the pointer is not on a field.
- New: while recording with the system proxy off, the status bar highlights the system proxy item and explains that only traffic manually pointed at the proxy port is captured, so Recording is not mistaken for full-device capture.
- New: the top Start / Stop Proxy button is larger and shows a pulsing dot with the recording duration (mm:ss, or h:mm:ss past one hour) while recording.
