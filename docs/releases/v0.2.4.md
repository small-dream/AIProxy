# AIProxy v0.2.4

## 更新内容

- 启动与停止更可靠：启动失败不再残留「运行中」状态，会自动回滚，并在系统代理已开启时提示如何恢复；停止抓包会等待采集队列排空，停止瞬间完成的请求不再丢失。
- 编码与签名接口更友好：在 Compose 中编辑一个 Query 参数不再重新编码整条查询串（`%20` 保持原样、空路径不会被补 `/`），签名类接口不会因此校验失败；只修改 Header 的脚本规则不再破坏 gzip / br 压缩响应体。
- 会话列表与检视：首次加载失败不再被当成「没有历史会话」；首次启动的列表宽度与分栏保持设计默认值，不再被压到最小值；大 Body / Raw 内容加载失败会给出提示并支持手动重试，不再在后台无限重试；媒体响应的 Overview 标签可以正常切回。
- 规则与导入导出：重命名或保存集合条目不再把它移到列表最前；连续点击规则导入只会执行一次，部分失败的数量按条目统计；从 curl 导入时支持 `-A`、`-b`、`-o`、`-x`、`--max-time` 等常见选项；HAR 导出的图片 / 字体等二进制 Body 使用标准 base64，可被本应用或其它 HAR 工具完整还原，导入时的大小统计与错误定位也更准确。
- 抓包细节：Mock 响应保留多个 `Set-Cookie`；上游返回非法 101 时，会话的 Raw / Headers 与实际返回的 502 一致；洞察页的主机统计不再区分大小写，同一主机不会被拆成两行。
- Agent / MCP 安全与兼容：标识符伪名改用每台机器随机生成的密钥（保存在数据目录的 `agent-redaction.key`），脱敏视图不再附带原文 SHA-256；未授予读取会话权限时，诊断工具不再返回最近失败会话的 host 与失败信息；Compare 页的 AI 差异请求会对 URL 中的签名 / token 参数脱敏；`get_websocket_messages` 现在接受 `client` / `server` 等方向别名。
- 文档与文案：帮助中心里跨指南的锚点链接可以直接跳到对应小节；设置页标题、限速页的阶段与时长均已完成中英文化。

## What's new

- Start and stop are more reliable: a failed start no longer leaves a stale "running" state — it rolls back and explains how to recover when the system proxy was enabled; stopping capture now waits for the collector to drain, so requests that finish at that moment are no longer lost.
- Friendlier to encoded and signed APIs: editing one query parameter in Compose no longer re-encodes the whole query string (`%20` stays as-is and an empty path is not turned into `/`), and header-only script rules no longer corrupt gzip / br response bodies.
- Session list and inspector: a failed first load is no longer treated as "no history"; first-run explorer width and split ratios keep their designed defaults instead of being clamped to the minimum; a failed large-body / raw load shows a notice with a manual retry instead of retrying forever in the background; the Overview tab stays reachable for media responses.
- Rules and import/export: renaming or saving a collection entry no longer moves it to the top of the list; repeated clicks on rule import only import once and partial failures are counted per entry; curl import supports common options such as `-A`, `-b`, `-o`, `-x`, and `--max-time`; HAR exports write binary bodies (images, fonts) as standard base64 so this app or any other HAR tool can restore them exactly, and imported sizes and error locations are more accurate.
- Capture details: mock responses keep multiple `Set-Cookie` values; when an upstream returns a malformed 101, the session's Raw / Headers match the 502 the client actually received; host statistics in Insights are case-insensitive so one host no longer splits into two rows.
- Agent / MCP security and compatibility: identifier pseudonyms now use a random per-machine key stored in `agent-redaction.key` in the data directory, and redacted views no longer include the original SHA-256; the diagnostics tool withholds recent failed-session hosts and messages without the read-sessions permission; AI diff requests on the Compare page redact signature / token parameters in URLs; `get_websocket_messages` accepts `client` / `server` direction aliases.
- Docs and copy: cross-guide anchor links jump to the intended section, and the Settings title plus throttling stage and duration text are now fully localized in both languages.
