# AIProxy v0.1.46

## 更新内容

- MCP 新增 JSON 字段精准提取：只返回 `jsonPaths` 指定的响应字段，并可搜索脱敏后的 Body 文本，不再为了一个 AB 实验分组读取整段响应。
- 新增批量字段读取：一次从最多 20 个会话提取同一组字段，适合对比多次请求的实验分组、开关和状态值。
- 会话检索更精确：支持按路径片段、Query 参数、相对时间筛选，并可按耗时、大小、状态码排序；`compact` / `fields` 可显著缩短返回结果。
- Body 返回信息更清晰：分别提供传输大小、解码后大小和脱敏视图大小，并明确区分抓包截断、扫描截断与分页未读完。
- 会话比较与聚合增强：JSON 响应可做结构化字段差异；Insights 可按接口路径或 Query 参数分组，快速定位最慢或最大的接口。
- 脱敏策略可配置：新增 JWT、邮箱、手机号、设备 ID 等格式识别、标识符稳定哈希和自定义敏感字段；设置页可直接搜索到脱敏策略。
- 已安装旧版 AIProxy Skill 的客户端会显示“需要更新”，重新连接即可升级到新版排查流程。

## What's new

- MCP now extracts only the JSON fields requested through `jsonPaths` and can search redacted body text, so one experiment flag no longer requires downloading the entire response.
- Batch field reads now pull the same paths from up to 20 sessions in one call, making it easier to compare experiment groups, flags, and status values across requests.
- Session search is more precise with path fragment, query parameter, and relative-time filters, plus sorting by duration, size, and status. `compact` and `fields` keep responses small.
- Body responses now distinguish wire size, decoded size, and redacted view size, with explicit capture, scan, and pagination truncation reasons.
- Session comparison and insights are stronger: JSON responses get structured field diffs, and insights can group by endpoint path or query parameter to find the slowest or largest endpoints.
- Redaction is configurable with JWT, email, phone, and device ID detection, stable identifier pseudonyms, and custom sensitive fields. The redaction policy is also searchable from Settings.
- Clients with an older installed AIProxy Skill now show “Needs update”; reconnect once to install the new investigation workflow.
