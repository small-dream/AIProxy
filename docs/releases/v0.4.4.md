# AIProxy v0.4.4

## 更新内容

- 中文界面统一使用更准确的网络调试术语，并补齐请求体类型的协议说明，帮助你快速区分请求头、请求体、查询参数和原始内容。
- 会话对比工作台的动态差异、字段标签、状态和 Body 说明现在会跟随界面语言切换，同时保留真实的消息头名称、参数名、JSON 路径和协议值。
- 改写规则摘要、规则模板和对比结果支持完整双语显示；新增测试覆盖语言切换、插值、协议标识保留和请求编辑器交互。

## What's new

- Chinese UI now uses consistent, accurate network-debugging terminology, with protocol details for request body types so you can distinguish headers, bodies, query parameters, and raw content at a glance.
- Dynamic session comparison diffs, field labels, statuses, and body explanations now follow the selected UI language while preserving actual header names, parameter names, JSON paths, and protocol values.
- Rewrite rule summaries, rule templates, and comparison results now support complete bilingual rendering; tests cover language switching, interpolation, protocol identifier preservation, and request-editor interactions.
