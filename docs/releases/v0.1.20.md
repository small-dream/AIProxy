# AIProxy v0.1.20

## 更新内容

- 收口 HTTP/2、Map Remote、TLS、上游代理、节流和 HAR 的协议正确性回归，异常连接会更快失效并避免错误复用。
- Map Remote 支持带 base path 的目标地址，自动规范路径拼接，并在 HTTP/HTTPS 跨协议映射时保留清晰的原始与最终请求上下文。
- 增强协议失败日志和发布冒烟清单，方便排查连接、证书、代理恢复和导出问题。

## What's new

- Tightened protocol-correctness regression coverage for HTTP/2, Map Remote, TLS, upstream proxies, throttling, and HAR; failed connections are evicted sooner to avoid incorrect reuse.
- Map Remote now supports target base paths with normalized joining and keeps clear original/final request context across HTTP/HTTPS protocol mappings.
- Improved protocol failure diagnostics and added a cross-platform release smoke checklist for connection, certificate, proxy recovery, and export verification.
