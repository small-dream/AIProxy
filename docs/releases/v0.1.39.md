# AIProxy v0.1.39

## 更新内容

- 改进：右键菜单里的复制类操作不再共用同一个图标，改为按含义区分的图标，一眼就能分清各自复制的内容。
- 改进：会话列表右键菜单中，`Copy URL`、`Copy Request`、`Copy cURL`、`Copy Response` 以及 `Set as Compare Base`、`Compare with Base` 各自使用独立图标。
- 改进：代码块（JSON 文本 / Raw / Text Body）的右键菜单中，`Copy Key`、`Copy Value`、`Copy Path` 使用不同图标；图片预览菜单中的 `Copy Image` 与 `Copy Image URL` 也做了区分。

## What's new

- Improved: copy actions in context menus no longer all share a single copy icon; each one now has an icon that reflects what it copies, so they are easy to tell apart at a glance.
- Improved: in the session list context menu, `Copy URL`, `Copy Request`, `Copy cURL`, `Copy Response`, `Set as Compare Base` and `Compare with Base` each use their own distinct icon.
- Improved: in the code block context menu (JSON Text / Raw / Text Body), `Copy Key`, `Copy Value` and `Copy Path` now use different icons; the image preview menu also distinguishes `Copy Image` from `Copy Image URL`.
