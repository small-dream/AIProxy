# AIProxy v0.3.0

## 更新内容

- Agent 自动化实验正式可用：在用户授权后，Agent 可创建、校验、应用、验证、回滚、提升和清理 Rewrite / Map Local 资源，并在 **Rules → Agent 实验** 中查看资源版本、证据、断言和清理状态。
- 新增离线变换、受控代理请求和真实客户端三级证据；代理验证只发送受限幂等请求，未命中、被覆盖、执行失败和断言失败会分别报告。
- Agent 接入新增六项默认关闭的自动化权限、Map Local 批准根目录和代理验证 origin 白名单；跨 host Redirect、Map Remote、Script、DNS、Throttle 与 Breakpoint 写入仍不可用。
- 强化安全与一致性：自动化输出按资源和断言来源脱敏；清理不会恢复出更早的 Agent 版本；常驻与临时生命周期冲突、重复计划操作和跨 host 变换会被明确拒绝。

## What's new

- Verified Agent automation experiments are now available. After you grant access, an Agent can create, validate, apply, verify, roll back, promote, and clean up Rewrite / Map Local resources, with resource versions, evidence, assertions, and cleanup state visible in **Rules → Agent Experiments**.
- Verification now offers three evidence levels: offline transformation, controlled proxy requests, and real-client sessions. Proxy verification sends only bounded idempotent requests, and reports not-matched, shadowed, execution-failure, and assertion-failure outcomes separately.
- Agent Access adds six automation permissions that are off by default, approved Map Local roots, and a separate proxy-verification origin allowlist. Cross-host Redirects and Map Remote, Script, DNS, Throttle, and Breakpoint writes remain unavailable.
- Security and consistency are stronger: automation output is redacted by resource and assertion source, cleanup never restores an older Agent version, and persistent/ephemeral lifecycle conflicts, duplicate plan mutations, and cross-host transformations are rejected explicitly.
