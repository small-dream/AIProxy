# AIProxy v0.4.0

## 更新内容

- Agent 接入的权限预设改为下拉框，新配置默认使用“只读分析（推荐）”；手动修改权限会自动切到“自定义”，套用其他预设后仍可返回最近一次自定义组合。
- 新增“批量授权…”：一次选择本版全部可用能力并写入草稿，未开放能力不会启用；保存时仍会再次确认高风险权限。
- 新配置默认读取脱敏 Body；未脱敏 Body、WebSocket、导出、控制与自动化权限仍默认关闭，已有配置不会自动迁移或扩大权限。
- 同步更新中英文界面、应用内帮助文档、PRD、权限体验方案、页面蓝图与 API 规范。

## What's new

- Agent Access permission presets now use a dropdown. New configurations default to **Read-only analysis (recommended)**. Manual edits switch to **Custom**, and you can return to the last custom combination after applying another preset.
- Added **Batch grant...** to select every capability available in this release as a draft in one step. Reserved capabilities are never enabled, and saving still requires the high-risk confirmation.
- New configurations now read redacted bodies by default. Unredacted bodies, WebSocket, export, control, and automation permissions remain off, and existing configurations are not migrated or broadened.
- Updated Chinese and English UI copy, in-app guides, product documentation, the permission plan, page blueprints, and API specification.
