# 会话检视使用指南

Sessions 是 AIProxy 的核心页面：所有经过代理的 HTTP / HTTPS / WebSocket 流量都会出现在这里，按域名和路径自动分组，你可以实时检视、筛选、搜索、对比和导出它们。

## 入口位置

1. 打开 AIProxy
2. 在左侧导航栏点击 **Sessions**（首页，路由 `/`）

页面分为左右两栏：左侧是会话浏览器（树形列表 + 筛选），右侧是当前选中会话的检视工作区。

## 会话容器（Session Container）

页面支持多个「会话容器」标签页，每个容器独立维护自己的会话集合和筛选状态，方便你把不同场景的流量隔开（例如「登录流程」「支付联调」）。

- 顶部 **新建会话容器** 按钮新建一个容器
- 每个容器标签页可单独关闭
- 当前正在录制流量的容器会显示 **录制中（Live）** 标识

> 容器也是 [会话对比](./session-compare.md) 的对比单元：你可以把两个容器放在一起对比调用行为。

## 会话浏览器

### 分组方式

会话按 **Host（域名）** 一级分组，再按 **Path** 层级展开成树。这样上百条请求也能按站点快速折叠定位。

- 没有归入任何聚焦域名的请求会进入 **Unfocused** 组
- 主机名缺失的请求会显示为 `<未知主机>`

### 每条会话展示

列表中每一行显示：

- **HTTP 方法**（GET / POST / …）
- **路径**（含 Query 后缀）
- **资源类型图标**：按响应内容自动识别，例如 JSON、JavaScript、CSS、HTML、图片、文本、WebSocket、文件等，并用不同颜色区分
- **状态**：等待中显示「等待中（Pending）」，完成后显示状态码；失败 / 取消有专门标识

### 筛选与搜索

- **过滤框**：按域名关键词过滤
- **搜索框**：按域名或路径关键词搜索
- **Throttled / 全部会话**：顶部切换，只看被 [限速](./throttling.md) 影响过的请求
- **清空会话**：清空当前容器的全部会话

### Host 聚焦与忽略

在域名分组上或单条会话上右键，可以：

- **Add Focus / Remove Focus**：把某域名设为「聚焦」域名，单独拎出来看
- **Ignore / Stop Ignoring**：忽略某域名（例如噪音埋点），不再出现在列表里

## 检视工作区

选中一条会话后，右侧分为 **Request** 和 **Response** 两大区。

### Request 区标签页

| 标签 | 内容 |
|---|---|
| Query | URL Query 参数键值对 |
| Form | 表单字段（检测到表单时） |
| Body | 请求 Body，支持搜索 |
| Headers | 请求头键值对 |
| Raw | 原始 HTTP 请求文本 |

### Response 区标签页

会根据响应类型动态出现不同标签：

| 标签 | 内容 |
|---|---|
| Overview | 概览：状态码、Content-Type、客户端地址、时间、大小、连接信息、时序瀑布图 |
| Headers | 响应头键值对 |
| JSON | 树形 JSON 查看器（可折叠、可搜索） |
| JSON Text | 格式化后的 JSON 文本，支持搜索 |
| Text | 纯文本内容，支持搜索 |
| Raw | 原始响应文本 |
| Preview | 图片等媒体的预览 |
| Messages | WebSocket 消息检视器（详见 [WebSocket 指南](./websocket-inspector.md)） |
| Automation | 命中的 [Rewrite](./rewrite-rules.md) / [脚本](./script-rules.md) / [限速](./throttling.md) 追踪记录 |
| Trailers | HTTP Trailer（存在时） |

### Body 大小限制

单个 Body 捕获上限为 **20 MB**，超出会在 20 MB 处截断（列表与检视都会提示）。过大的 JSON 无法用树形视图渲染时，请改用 **JSON Text** 或 **Raw** 查看。

## 右键菜单操作

在会话上右键，可用的操作大致分几组：

- **复制**：复制 URL / 复制请求 / 复制 cURL / 复制响应
- **对比**：设为对比基准（Set as Compare Base）、与基准对比（Compare with Base）—— 用于 [会话对比](./session-compare.md)
- **保存 / 导出**：保存响应、导出请求、保存到 [集合](./collections-and-environments.md)
- **请求操作**：构造请求（带入 [Compose](./compose.md)）、重复请求、保存到集合
- **创建规则**：基于该请求创建 Rewrite 规则 / 限速规则 / 断点 / 映射规则
- **Host 管理**：Add/Remove Focus、Ignore/Stop Ignoring
- **清除其他会话**：只保留当前会话

在域名分组上右键，还可以 **导出 Host**、对该域名 Focus / Ignore。

## 导入与导出

AIProxy 支持 **HAR** 格式：

- **导出**：可选择范围 —— 全部会话 / 当前筛选结果 / 当前 Domain / 当前选中会话，导出为 `.har` 文件
- **导入**：把一个 HAR 文件加载进当前工作区，方便继续查看、筛选和再次导出

## 性能

会话列表使用虚拟滚动（只渲染可见行），即使上千条会话也能流畅滚动；WebSocket 消息在内存中最多保留约 10000 条，超出自动裁剪旧消息。

## 常见问题

### Q: 为什么有些会话只显示「等待中」？

请求已发出但响应还没回来（或连接挂起），状态码此时为「等待中」。请求被取消时会显示「已取消」。

### Q: 能不能只看某个接口？

可以。用搜索框输入路径关键词，或对该接口所在域名 **Add Focus**，再用过滤框缩小范围。也可以右键单条请求创建定向规则。

### Q: Body 显示被截断了？

单条 Body 超过 20 MB 会截断。如果 JSON 太大无法渲染树形视图，切到 **JSON Text** 或 **Raw** 即可查看。

### Q: Compose 发出的请求会出现在这里吗？

会。在 [Compose](./compose.md) 页发送的请求会以会话形式插入列表，可以像普通抓包一样检视和对比。

### Q: 如何把抓到的请求拿去反复调试？

右键该请求 → **保存到集合**（持久化到 [Collections](./collections-and-environments.md)），或 **构造请求**（带入 Compose 直接重发）。
