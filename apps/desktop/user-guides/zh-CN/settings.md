# 设置（Settings）使用指南

设置页集中管理代理参数、上游代理、SSL 代理策略、AI 模型、外观与语言、通知与确认，以及软件更新。证书安装与抓包就绪流程请看 [证书安装与抓包排障](./certificate-setup.md)，本页主要做日常配置调整。

## 入口位置

1. 在左侧导航栏点击 **设置（Settings）**

页面分为 **代理预设**、**上游代理**、**SSL / TLS**、**AI 模型**、**外观与语言**、**通知与确认**、**软件更新**、**关于** 分区。左侧目录可直接跳转；顶部 **搜索设置** 支持按中英文关键词定位具体设置项，搜索结果会跳到对应分区并高亮该行。

> 系统代理的「开 / 关」不在设置页，而在应用顶部的控制栏。设置页只配置代理本身的参数。

## 代理设置

| 选项 | 说明 | 默认 |
|---|---|---|
| 代理端口（Proxy Port） | 代理监听端口，范围 1–65535 | `8888` |
| 启用 SSL（SSL Enabled） | 是否解密 HTTPS；关闭则只转发不解密，无法抓到明文 | 开启 |
| HTTP/2 支持 | 捕获连接是否启用 HTTP/2；关闭后全部回退 HTTP/1.1 | 开启 |
| 校验上游 TLS（Verify Upstream TLS） | 在新的 HTTPS/WSS 连接上依据系统根证书校验上游服务器证书。默认关闭：代理接受任何上游证书，便于拦截但不安全；关闭时界面会给出警告提示 | 关闭 |
| TLS 校验主机白名单（TLS Verify Hosts） | 每行一个主机名（开启「校验上游 TLS」后显示）。列表中的主机始终强制校验，即使全局开关关闭——适合只对特定上游开启校验而不全局打开 | — |

点 **保存（Save）** 生效：

- 如果代理**正在运行**，保存后会**立即重启代理**应用新参数
- 如果代理**已停止**，新参数会在**下次启动代理**时生效

> 改端口或 SSL 后，记得确认抓包链路仍就绪（参考 [证书指南](./certificate-setup.md) 里的 `captureReady` 条件，SSL 解密开启是其中之一）。

## AI 模型

为 [会话对比](./session-compare.md) 的 **AI 差异总结** 提供模型。当前支持 **OpenAI 兼容**接口。

| 字段 | 说明 | 默认 |
|---|---|---|
| 厂商（Provider） | 模型供应商 | OpenAI-compatible |
| Base URL | API 基地址 | `https://api.openai.com/v1` |
| 模型（Model） | 模型名称 | `gpt-4.1-mini` |
| API Key | 密钥；留空则保留已保存的 Key，可用「清除 Key」删除 | — |
| Temperature | 采样温度 | `0.2` |
| 超时（Timeout） | 请求超时（毫秒） | `60000` |

操作：

- **测试连接（Test Connection）**：用当前配置发一次探测，验证 Key / Base URL / 模型是否可用
- **保存（Save）**：保存配置，立即生效

> 第三方 OpenAI 兼容服务（自建网关、Azure 兼容端点等）把 Base URL 换成对应地址即可。会话对比发送前会做敏感字段脱敏，可在对比页 **预览 AI Payload** 确认。

## 上游代理

开启 **经由上游代理转发** 后，AIProxy 仍负责拦截和解密流量；实际出网请求交给另一个 HTTP CONNECT、HTTPS 或 SOCKS5 代理。适合把手机/客户端流量先接入 AIProxy，再链到本机或其他规则代理。

- 填写上游代理的协议、地址和端口；需要认证时填写用户名和密码
- 可用 **测试连接** 验证能否建立到目标地址的隧道
- **绕行列表** 中命中的主机继续直连；支持精确域名、`*.example.com` 后缀通配，以及 CIDR 网段（CIDR 只对 IP 字面量目标生效）
- 上游不可用时请求直接失败，不会静默回退直连

密码会以明文保存在当前工作区的本地数据库中；请勿在共享或不受信任的机器上保存敏感凭据。

## SSL / TLS

除「代理预设」中的总开关外，这里可以精确控制哪些域名解密：

| 控件 | 说明 | 默认 |
|---|---|---|
| 只看包含列表中的域名 | 开启后仅解密包含列表中已启用的域名，其余盲转发；关闭后解密除排除列表以外的全部域名 | 关闭 |
| 包含列表 / 排除列表 | 每条域名规则可单独启用/禁用，也可删除；禁用条目保留在列表中但不影响匹配 | — |
| 启用排除列表 | 命中排除列表的域名始终不解密，即使命中包含列表也一样。关闭可能使 TikTok、iCloud 等绑定证书的 App 无法使用 | 开启 |

标题下方有一行说明文字，实时反映当前模式（「当前：解密除排除列表以外的全部域名。」/「当前：仅解密包含列表中已启用的域名。」）。如果「代理预设」里的 SSL 总开关是关的，这里会显示提示条：该策略暂不生效，重新开启 SSL 后恢复。

排除列表预置了推荐项，用于绕过 iCloud、TikTok 等常见使用证书绑定的服务。从未配置过 SSL 代理的工作区会预置这些推荐项（已启用），且在推荐列表加载成功前无法保存——避免内置防护被意外清空。点 **恢复推荐列表** 可找回内置防护（同时会重新启用排除列表）；长列表在固定高度区域内滚动显示。修改后点 **保存**；代理运行中会自动重启使其生效。

## 软件更新

- **检查更新（Check for Updates）**：手动检查 GitHub Releases 是否有新版本；顶部栏的更新图标按钮和菜单栏 **帮助 → 检查更新**（Windows/Linux）也可以进入

## 设置持久化

- 代理参数（端口 / SSL / HTTP/2）随工作区配置持久化
- AI 模型配置通过后端持久化
- 语言、主题、字体、字体大小等偏好持久化在本地（应用重启后保留）

## 生效方式速查

| 设置 | 生效方式 |
|---|---|
| 语言 / 主题 / 字体 / 字号 | 立即生效 |
| AI 模型配置 / 测试连接 | 立即生效 |

| 软件更新 | 安装后自动重启应用 |

## 常见问题

### Q: 改了端口为什么没生效？

保存时如果代理正在运行会自动重启；如果代理没运行，需要手动启动代理才会用新端口。端口冲突时会提示端口被占用。

### Q: SSL 解密关掉会怎样？

代理只转发 HTTPS 不解密，你将看不到 HTTPS 请求的明文内容，`captureReady` 也不再成立。需要抓 HTTPS 明文就要开启 SSL 并信任根证书。

### Q: 会话对比里 AI 总结用不了？

先到设置页 **AI 模型** 区填好 Base URL / 模型 / API Key，点 **测试连接** 确认可用，再回对比页生成总结。

### Q: 自定义字体填了不生效？

确认字体名拼写正确、字体已安装在本机；内容字体若选「跟随界面字体」则跟随界面字体设置。

### Q: 设置存在哪里？换电脑能迁移吗？

代理和 AI 配置随工作区 / 后端存储；外观与语言偏好是本机本地存储。换电脑需重新配置。
