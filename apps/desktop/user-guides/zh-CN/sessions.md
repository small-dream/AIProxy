# 会话检视使用指南

会话是 AIProxy 的核心页面：所有经过代理的 HTTP / HTTPS / WebSocket 流量都会出现在这里，按域名和路径自动分组，你可以实时检视、筛选、搜索、对比和导出它们。

## 入口位置

1. 打开 AIProxy
2. 在左侧导航栏点击 **会话**（首页，路由 `/`）

页面分为左右两栏：左侧是会话浏览器（树形列表 + 筛选），右侧是当前选中会话的检视工作区。

代理运行后，会话页顶部会显示 **记录中** 和累计录制时长。若代理正在运行但系统代理未开启，状态栏会提示当前只会收到显式指向代理端口的流量；需要自动接管应用流量时，请打开系统代理。

## 会话容器（会话 Container）

页面支持多个「会话容器」标签页，每个容器独立维护自己的会话集合和筛选状态，方便你把不同场景的流量隔开（例如「登录流程」「支付联调」）。

- 顶部 **新建会话容器** 按钮新建一个容器
- 活动标签上的 ✕ 关闭当前容器（容器多于一个时才显示 ✕）；后台标签不能直接关闭——先切换过去再关

> 容器也是 [会话对比](./session-compare.md) 的对比单元：你可以把两个容器放在一起对比调用行为。

## 会话浏览器

### 分组方式

会话按 **主机（域名）** 一级分组，再按 **路径** 层级展开成树。这样上百条请求也能按站点快速折叠定位。

- 没有归入任何聚焦域名的请求会进入 **未聚焦** 组
- 主机名缺失的请求会显示为 `<未知主机>`

### 每条会话展示

列表中每一行显示：

- **HTTP 方法**（GET / POST / …）
- **路径**（含查询参数后缀）
- **资源类型图标**：按响应内容自动识别，例如 JSON、JavaScript、CSS、HTML、图片、文本、WebSocket、文件等，并用不同颜色区分
- **状态**：等待中显示「等待中（Pending）」，完成后显示状态码；请求取消、HTTP 错误和连接失败使用不同标识。DNS 失败、连接被拒绝、TLS 握手失败等在尚未收到 HTTP 响应时也会保留为「连接失败」会话，不再一直显示转圈。

### 多选与键盘导航

`Ctrl/Cmd`+点击把会话加入多选，`Shift`+点击选中一个区间；`↑`/`↓` 移动选择，`Home`/`End` 跳到首行/末行，`Esc` 取消选择。有选中行时会出现批量操作栏，提供导出（HAR）、保存响应、删除（带确认）和清空。多选范围只作用于当前筛选下可见的会话。

### 筛选与搜索

- **搜索框**（列表下方）：匹配任意字段——URL / 域名、路径、方法、状态码、MIME 类型、协议
- **失败检索**：本页可用状态码和关键词定位错误；通过 [Agent 接入](./agent-access.md) 查询时，还可使用 `failedOnly`、`failureKind`、`failureOrigin` 精确筛选连接失败、TLS、超时和上游错误
- **聚焦 / 忽略标签**：聚焦与忽略的域名会以可移除的标签形式显示在列表上方（限速激活时是警告色标签）；某类域名过多时会折叠成一个汇总标签，点开气泡可逐个移除
- **Throttled / 全部会话**：顶部切换，只看被 [限速](./throttling.md) 影响过的请求
- **清空会话**：清空当前容器的全部会话；在确认框里勾选「不再询问」可跳过确认（之后可在设置 → 通知与确认里重新开启）

### 主机聚焦与忽略

在域名分组上或单条会话上右键，可以：

- **聚焦此域名 / 取消聚焦**：把某域名设为「聚焦」域名，单独拎出来看
- **忽略此域名 / 取消忽略**：忽略某域名（例如噪音埋点），不再出现在列表里

## 检视工作区

选中一条会话后，右侧分为 **请求** 和 **响应** 两大区。`Ctrl/Cmd + F` 打开当前面板的内容搜索条（支持区分大小写 / 全字匹配 / 正则）。

### 请求区标签页

| 标签 | 内容 |
|---|---|
| 查询参数 | URL 查询参数键值对 |
| 表单 | 表单字段（检测到表单时） |
| 请求体 | 请求体，支持搜索 |
| 请求头 | 请求头键值对 |
| 原始内容 | 原始 HTTP 请求文本 |

### 响应区标签页

会根据响应类型动态出现不同标签：

| 标签 | 内容 |
|---|---|
| 概览 | 概览：状态码、失败原因与失败详情、Content-Type、客户端地址、时间、大小、连接信息、时序瀑布图 |
| 响应头 | 响应头键值对 |
| JSON | 树形 JSON 查看器（可折叠、可搜索） |
| JSON 文本 | 格式化后的 JSON 文本，支持搜索 |
| 文本 | 纯文本内容，支持搜索 |
| 原始内容 | 原始响应文本 |
| 预览 | 图片等媒体的预览 |
| 消息 | WebSocket 消息检视器（详见 [WebSocket 指南](./websocket-inspector.md)） |
| 自动化 | 命中的 [改写](./rewrite-rules.md) / [脚本](./script-rules.md) / [限速](./throttling.md) 追踪记录 |
| 尾部字段 | HTTP 尾部字段（存在时） |

时序区域按连接池等待、DNS、建立连接、TLS、发送、等待和下载等阶段展开。复用已建立的连接时，DNS / 连接 / TLS 可能显示 **复用连接**；当同一主机的连接仍在建立、请求需要排队时，会单独显示 **连接等待**，避免这段延迟被计入 DNS 或 TCP 阶段。

请求失败时，概览的概览分组会多出两行：**失败原因** 显示“来源 · 类型”（例如 `upstream · connect_timeout`），**失败详情** 显示经过长度限制与脱敏的说明。失败的来源和类别由代理链路在失败发生时记录，历史会话不会补造原因；如果没有这两行，说明该会话没有被标记为失败。

### 消息体大小限制

单个消息体捕获上限为 **20 MB**，超出会在 20 MB 处截断（列表与检视都会提示）。过大的 JSON 无法用树形视图渲染时，请改用 **JSON 文本** 或 **原始内容** 查看。

大消息体或原始内容是切换到对应标签页时才按需加载的。如果这次加载失败，检查器顶部会给出提示并提供 **重试**，不会在后台无限重试；切换会话后状态会重置。

### 会话保留上限

单次运行最多保留 **15000** 条会话。超出上限后，最久远且未被聚焦的主机会话会被自动回收：从列表移除，并同时删除它的数据库记录与消息体文件（因此洞察、检索和磁盘占用始终与列表一致）。会话本身不跨启动保留——重新打开 AIProxy 时会清空上一次抓到的会话。需要长期保留某次请求时，请先导出 HAR 或保存响应。

## 右键菜单操作

在会话上右键，可用的操作大致分几组：

- **复制**：复制 URL / 复制请求 / 复制 cURL / 复制响应
- **对比**：设为对比基准（Set as 对比 Base）、与基准对比（对比 with Base）—— 用于 [会话对比](./session-compare.md)
- **保存 / 导出**：保存响应、导出请求、保存到 [集合](./collections-and-environments.md)
- **请求操作**：构造请求（带入 [构造请求](./compose.md)）、重复请求、保存到集合、导出请求
- **创建规则**：改写 / 限速规则 / 本地映射会基于该请求预填；**断点（Breakpoints…）** 只是打开断点标签页，不会基于该请求生成规则
- **SSL 解密**：对主机启用/禁用 SSL 解密——排除的域名盲转发（不解密），代理运行中会自动重启使其生效
- **域名管理**：聚焦此域名 / 取消聚焦、忽略此域名/取消忽略
- **清除其他会话**：只保留当前会话

在域名分组上右键，还可以 **复制主机 URL**（复制协议 + 主机 + 显式端口，不含路径与查询参数）、**导出主机会话**、对该域名聚焦 / 忽略。路径文件夹节点提供 **保存全部文件…**（见[导入与导出](#导入与导出)）。

## 导入与导出

AIProxy 支持 **HAR** 格式：

- **导出**：可选择范围 —— 全部会话 / 当前筛选结果 / 当前域名 / 当前选中会话，导出为 `.har` 文件
- **导入**：把一个 HAR 文件加载进当前工作区，方便继续查看、筛选和再次导出

二进制消息体（图片、字体、压缩包等）以 HAR 标准的 `encoding: "base64"` 导出，能原样往返本应用或其它 HAR 工具；文本消息体仍以可读文本导出。导入时消息体大小按 UTF-8 字节数与解码后字节数统计；某条记录的 URL 非法时，报错会指出是第几条。

### 把抓到的文件保存到磁盘

右键任意路径文件夹节点或域名分组 → **保存全部文件…**：先选择重名处理方式（「只保留最后一次请求」或「每次请求都保存」，后者自动加 `名称 (1).ext` 后缀），再选择目标文件夹，响应体会按 URL 路径结构写入域名目录下——缺失扩展名时按 MIME 推断；WebSocket 与无消息体的请求会跳过。完成后通过 snackbar 报告成功 / 跳过 / 失败数量。

## 性能

会话列表使用虚拟滚动（只渲染可见行），即使上千条会话也能流畅滚动；WebSocket 消息在内存中最多保留约 10000 条，超出自动裁剪旧消息。

## 常见问题

### Q: 为什么有些会话只显示「等待中」？

请求已发出但响应还没回来（或连接挂起），状态码此时为「等待中」。约两分钟后仍无响应，等待中的条目会变为 504（Gateway 超时），不会永远挂起。请求被取消时会显示「已取消」。

### Q: 「连接失败」和普通的 4xx / 5xx 有什么区别？

「连接失败」表示请求尚未得到 HTTP 响应，例如 DNS 解析失败、连接被拒绝、连接超时或 TLS 握手失败；此时状态码为 0，概览会展示结构化的失败原因。4xx / 5xx 表示已经收到上游响应，属于 HTTP 错误而不是连接阶段失败。

### Q: 能不能只看某个接口？

可以。用搜索框输入路径关键词，或对该接口所在域名 **聚焦此域名**，再用过滤框缩小范围。也可以右键单条请求创建定向规则。

### Q: 消息体显示被截断了？

单条消息体超过 20 MB 会截断。如果 JSON 太大无法渲染树形视图，切到 **JSON 文本** 或 **原始内容** 即可查看。

### Q: 构造请求发出的请求会出现在这里吗？

会。在 [构造请求](./compose.md) 页发送的请求会以会话形式插入列表，可以像普通抓包一样检视和对比。

### Q: 如何把抓到的请求拿去反复调试？

右键该请求 → **保存到集合**（持久化到 [Collections](./collections-and-environments.md)），或 **构造请求**（带入构造请求直接重发）。
