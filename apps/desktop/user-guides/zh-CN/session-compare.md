# 会话对比使用指南

对比让你把两条请求、或两组请求放在一起比较差异，快速发现参数、消息头、消息体、响应或调用行为上的差异，并能用 AI 生成一份差异总结。

## 两种对比模式

| 模式 | 对比对象 | 关注点 |
|---|---|---|
| **请求对比** | 两条独立请求 | 参数、消息头、消息体、响应、时序的差异 |
| **会话对比** | 两组请求（会话容器） | 请求频率、调用次数、接口覆盖、调用顺序 |

## 入口位置

1. 在左侧导航栏点击 **对比**

页面左侧是差异工作台，右侧是固定宽度的 **AI 总结** 面板（标题栏会显示当前配置的模型名）。

> 也可以在 [会话](./sessions.md) 里用右键的 **设为对比基准** / **与基准对比** 快速把请求送进请求对比。

## 请求对比

### 选择两条请求

用 **左侧请求 / 右侧请求** 两个下拉，从已捕获的会话里各选一条。两侧选中同一条请求（或同一个容器）时会显示「请选择两条不同的会话」警告而不是差异。选择会同步到 URL 参数，方便分享或保存对比状态。

### 对比维度

选中后会逐项给出差异：

| 维度 | 内容 |
|---|---|
| 概览 | 方法、URL、状态码、耗时、大小、协议、MIME |
| 查询参数 | URL 查询参数差异 |
| 请求头 | 请求头差异 |
| 请求体 | 请求体差异 |
| 响应头 | 响应头差异 |
| 响应体 | 响应体差异 |
| 时序 | DNS / 连接 / TLS / 发送 / 等待 / 读取各阶段耗时 |

每个维度上方有统计（新增 / 删除 / 修改 / 不变的数量），下方列出每条差异的左右值。

### 消息体差异

- 消息体默认折叠，点 **计算消息体差异** 展开计算
- JSON 内容走**语义差异**（按字段路径递归比对，标注新增 / 删除 / 修改）
- 非 JSON 内容走**文本行级差异**
- 左右两侧消息体文本合计超过 256,000 字符时，详细差异会整体跳过并提示；能计算时展示也只取前 240 条差异条目

## 会话对比

### 选择两组请求

用 **左侧会话 / 右侧会话** 两个下拉，各选一个**会话容器**（在会话页用「新建会话容器」创建）。可选定某些域名做进一步过滤。

### 对比维度

| 维度 | 内容 |
|---|---|
| 概览 | 总请求数、成功 / 失败数、域名数、总字节、状态码分布、耗时统计 |
| 域名 | 各域名的请求数、占比、差值 |
| 接口 | 各接口调用次数、平均耗时、状态码分布、变化类型 |
| 时间线 | 按时间桶统计两侧请求分布 |
| 调用顺序 | 接口调用顺序对比、新增 / 缺失接口、重复调用 |

适合回答「这两次操作调用的接口、顺序、频次有没有差别」这类问题。

## AI 差异总结

右侧 **AI 总结** 面板可以把当前差异发给 AI 生成一份 Markdown 总结。

### 前置条件

需要在 **设置** 里配置一个 **OpenAI 兼容**的 AI 模型：

- API 密钥
- 服务地址
- 模型名称
- （可选）温度、超时

未配置时面板会提示并提供 **配置 AI 模型** 按钮跳转到设置页。

### 使用

1. 选好对比对象、等差异计算完成
2. 点 **生成总结**
3. 生成的 Markdown 总结会渲染在面板里

### 隐私与脱敏

- 发送前可点 **预览 AI 载荷** 查看完整输入 JSON，确认要发什么
- 敏感字段（如 token、password 等）会自动脱敏
- URL 同样会脱敏：`?token=`、`?access_token=`、`?code=`、`?signature=`、`?sig=`、`X-Amz-Signature` 等敏感查询参数值，以及 `user:password@host` 形式的凭据，都会替换为 `[REDACTED]`；其它参数与编码保持原样
- 是否把消息体内容包含进 AI 输入由开关控制；本地计算脱敏后才上传

## 常见问题

### Q: AI 总结按钮是灰的？

需要先在设置里配置好 AI 模型（API 密钥 / 服务地址 / 模型），并等差异计算完成。

### Q: 请求对比里消息体为什么默认不展开？

消息体差异计算量较大，默认折叠以加快首屏。需要时点 **计算消息体差异** 即可。

### Q: 会话行为对比里选不到容器？

需要先在会话页面用 **新建会话容器** 创建至少两个容器，并把不同场景的流量分别抓到各自容器里。

### Q: 消息体太大差异不全？

左右两侧消息体文本合计超过 256,000 字符时会跳过详细差异并提示实际大小；能计算时最多展示前 240 条差异。如需完整对比，建议缩小请求本身的消息体，或聚焦关键字段。

### Q: 对比状态能分享吗？

可以。对比模式和请求对比的左右选择都会同步到 URL 参数（`mode`、`left`、`right`、作用域和域名过滤），复制当前 URL 即可还原同样的对比配置。
