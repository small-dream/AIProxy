# 会话对比（Compare）使用指南

Compare 让你把两条请求、或两组请求放在一起做 diff，快速发现参数、Headers、Body、响应或调用行为上的差异，并能用 AI 生成一份差异总结。

## 两种对比模式

| 模式 | 对比对象 | 关注点 |
|---|---|---|
| **请求对比（Request Compare）** | 两条独立请求 | 参数、Headers、Body、响应、时序的差异 |
| **会话行为对比（Session Compare）** | 两组请求（会话容器） | 请求频率、调用次数、接口覆盖、调用顺序 |

## 入口位置

1. 在左侧导航栏点击 **对比（Compare）**

页面左侧是 diff 工作台，右侧是 AI 总结面板（可折叠）。

> 也可以在 [Sessions](./sessions.md) 里用右键的 **设为对比基准** / **与基准对比** 快速把请求送进请求对比。

## 请求对比（Request Compare）

### 选择两条请求

用 **左侧请求 / 右侧请求** 两个下拉，从已捕获的会话里各选一条。选择会同步到 URL 参数，方便分享或保存对比状态。

### 对比维度

选中后会逐项给出差异：

| 维度 | 内容 |
|---|---|
| 概览 | 方法、URL、状态码、耗时、大小、协议、MIME |
| Query | URL 查询参数差异 |
| 请求 Headers | 请求头差异 |
| 请求 Body | 请求体差异 |
| 响应 Headers | 响应头差异 |
| 响应 Body | 响应体差异 |
| 时序 | DNS / 连接 / TLS / 发送 / 等待 / 读取 各阶段耗时 |

每个维度上方有统计（新增 / 删除 / 修改 / 不变的数量），下方列出每条差异的左右值。

### Body diff

- Body 默认折叠，点 **计算 Body diff** 展开计算
- JSON 内容走**语义 diff**（按字段路径递归比对，标注新增 / 删除 / 修改）
- 非 JSON 内容走**文本行级 diff**
- 超大 Body 会被截断保护（约 256 KB），并提示已截断

## 会话行为对比（Session Compare）

### 选择两组请求

用 **左侧会话 / 右侧会话** 两个下拉，各选一个**会话容器**（在 Sessions 页用「新建会话容器」创建）。可选定某些 Domain 做进一步过滤。

### 对比维度

| 维度 | 内容 |
|---|---|
| 概览 | 总请求数、成功 / 失败数、Domain 数、总字节、状态码分布、耗时统计 |
| Domains | 各域名的请求数、占比、差值 |
| Endpoints | 各接口调用次数、平均耗时、状态码分布、变化类型 |
| Timeline | 按时间桶统计两侧请求分布 |
| Sequence | 接口调用顺序对比、新增 / 缺失接口、重复调用 |

适合回答「这两次操作调用的接口、顺序、频次有没有差别」这类问题。

## AI 差异总结

右侧 **AI 总结** 面板可以把当前 diff 发给 AI 生成一份 Markdown 总结。

### 前置条件

需要在 **设置** 里配置一个 **OpenAI 兼容**的 AI 模型：

- API Key
- Base URL
- 模型名称
- （可选）Temperature、超时

未配置时面板会提示并提供 **配置 AI 模型** 按钮跳转到设置页。

### 使用

1. 选好对比对象、等 diff 计算完成
2. 点 **生成总结**
3. 生成的 Markdown 总结会渲染在面板里

### 隐私与脱敏

- 发送前可点 **预览 AI Payload** 查看完整输入 JSON，确认要发什么
- 敏感字段（如 token、password 等）会自动脱敏
- 是否把 Body 内容包含进 AI 输入由开关控制；本地计算脱敏后才上传

## 常见问题

### Q: AI 总结按钮是灰的？

需要先在设置里配置好 AI 模型（API Key / Base URL / 模型），并等 diff 计算完成。

### Q: 请求对比里 Body 为什么默认不展开？

Body diff 计算量较大，默认折叠以加快首屏。需要时点 **计算 Body diff** 即可。

### Q: 会话行为对比里选不到容器？

需要先在 Sessions 页面用 **新建会话容器** 创建至少两个容器，并把不同场景的流量分别抓到各自容器里。

### Q: Body 太大 diff 不全？

Body 超过约 256 KB 会截断保护。如需完整对比，建议缩小请求本身的 Body，或聚焦关键字段。

### Q: 对比状态能分享吗？

可以。请求对比的左右选择会同步到 URL 参数，复制当前 URL 即可还原同样的对比配置。
