# 弱网模拟弱网模拟使用指南

## 功能简介

弱网模拟用于在代理层模拟弱网环境，例如高延迟、低带宽、丢包、上传慢或下载慢。它适合移动端、前端页面、客户端应用和 API 联调中的网络健壮性测试。

在 AIProxy 中，弱网模拟指的是**弱网 / 链路模拟**，不是 API 网关里的 QPS 限流、并发限制、配额或 `429 Too Many Requests`。

## 典型用途

- **验证弱网加载体验**：检查页面骨架屏、loading、重试提示是否合理
- **测试移动网络场景**：模拟 4G、Slow 3G、弱 Wi-Fi 等环境
- **排查接口慢响应体验**：只对某个接口增加延迟，观察前端或客户端表现
- **验证上传 / 下载边界**：模拟上传慢、下载慢对业务流程的影响
- **测试丢包恢复**：模拟请求被弱网丢弃后的错误提示、重试或降级逻辑
- **回归关键链路**：对登录、支付、搜索、首屏接口等高风险路径建立固定弱网规则

## 入口位置

1. 打开 AIProxy
2. 在左侧导航栏点击 **弱网模拟 / 弱网**
3. 页面顶部是运行状态区，左侧是 **预设 / 规则** 切换，右侧是对应编辑器

也可以在会话列表中右键某条请求，点击 **Create 弱网模拟规则**，AIProxy 会基于当前请求生成一条定向弱网规则草稿。

## 当前版本能力

当前版本支持：

- 全局预设：对当前 Workspace 的代理流量启用一组弱网参数
- 预设预设：例如 Fast 4G、Slow 3G、Lossy Wi-Fi
- 自定义预设：配置延迟、上行、下行、丢包率
- 定向规则：按 URL 模式（支持匹配方式）、HTTP 方法、阶段、优先级控制弱网作用范围
- 15 分钟临时启用并显示倒计时；到期自动关闭（应用保持运行时）
- 规则行内开关启停 + 规则复制
- 一键关闭全局弱网
- 会话自动化标签页展示弱网模拟 Trace
- 会话列表可切换只查看被弱网影响的请求
- 会话右键创建定向弱网规则
- 通过规则页的单文件导入导出做备份（[详见](./rewrite-rules.md#规则导入--导出)）

当前版本暂不支持：

- Jitter 随机抖动
- 超时 / Offline 场景参数
- WebSocket 消息级限速
- 保存前测试器
- API QPS / 配额 / 并发限流

### Agent 自动化边界

首版 Agent 自动化工具不能创建、更新、删除或激活弱网预设 / 规则，也不能启动 15 分钟临时弱网。相关计划与 activation 返回 `FEATURE_NOT_AVAILABLE`；`manageGlobalAutomation` 等预留权限不会绕过该限制。

Agent 可以读取已捕获请求的时序、弱网模拟 Trace、丢包与延迟结果来帮助分析，但不能替你修改弱网配置。需要新增、调整或启用弱网时，请在本页手动操作，并在调试结束后关闭全局弱网。

## 页面结构

### 顶部运行状态区

顶部状态区用于确认弱网是否正在影响流量。

展示内容：

| 区域 | 说明 |
|---|---|
| 开关状态 | 当前弱网是否开启 |
| Active 预设 | 当前全局生效的预设 |
| Hits | 已命中的弱网请求数 |
| Drops | 因丢包被模拟失败的请求数 |
| Delay | 累计增加的 request / response 延迟 |
| 15 min | 临时启用当前选中的预设 |
| 关闭弱网 | 立即关闭全局弱网 |

建议：测试结束后点击 **关闭弱网**，避免后续抓包受到弱网影响。

临时启用期间会显示倒计时标签和「全局预设 + N 条定向规则」的范围说明。注意倒计时在应用层计时——如果中途重启 AIProxy，临时启用的预设会保持生效状态，直到你手动关闭。

### 预设

预设是可复用的弱网参数集合。

每个预设包含：

| 字段 | 说明 | 示例 |
|---|---|---|
| 预设 Name | 配置名称 | `Slow checkout API` |
| Latency | 给每个请求和响应阶段各增加的固定延迟（0–2000 ms） | `300 ms` |
| Download | 响应下载带宽，按 chunk 渐进交付（1–100,000 kbps） | `768 kbps` |
| Upload | 请求上传带宽；上传消息体会先缓冲，再按计算出的延迟发出（1–50,000 kbps） | `320 kbps` |
| Packet Loss | 请求或响应阶段各自被丢弃的概率（0–100%） | `1.2%` |
| Enable after save | 保存后是否立即作为全局预设启用 | 开启 / 关闭 |

常用操作：

- 点击预设或自定义预设，可在右侧查看和编辑
- 点击 **Apply**，把该预设作为全局弱网配置临时启用 **15 分钟**（顶部会出现倒计时标签）
- 点击 **New Custom**，创建自定义弱网配置
- 点击 **Save 预设**，保存配置但不一定启用
- 点击 **Save & Apply**，保存并保持全局启用，直到手动关闭弱网

## 全局弱网与定向规则

AIProxy 当前有两种弱网生效方式。

### 全局预设

全局预设会影响当前 Workspace 下经过代理的请求。

适合：

- 快速验证整个页面或 App 在弱网下的表现
- 做一轮完整弱网回归
- 不关心具体接口，只想整体模拟网络变差

注意：

- 全局预设影响范围较大
- 如果只想测试某个接口，建议使用定向规则
- 测试结束后记得关闭

### 定向规则

定向规则只影响匹配到的请求。它适合精准测试某个接口、域名或方法。

规则字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| 规则 name | 规则名称 | `Slow login API` |
| Enabled | 是否启用该规则（列表内也可行内开关） | 开启 |
| 预设 | 命中后使用的弱网预设——仅当该预设处于启用状态时规则才会生效 | `Slow 3G` |
| URL 模式 | 匹配完整请求 URL，按匹配方式解释 | `*://api.example.com/login*` |
| 匹配方式 | 模式匹配方式：包含（默认）/ 通配符 / 精确 / 正则 | 通配符 |
| Methods | 匹配 HTTP 方法，留空表示全部 | `POST` |
| 阶段 | 作用阶段 | `Request + response` |
| 优先级 | 优先级，数字越大越优先 | `100` |

编辑器还提供 **Duplicate（复制）**，可以基于现有规则快速创建新规则。

当定向规则与全局预设同时存在时：

1. 如果请求命中某条启用的规则、且其引用的预设也处于启用状态，使用该规则指定的预设
2. 多条规则同时命中时，优先级最高的规则生效
3. 如果没有命中任何规则，再使用全局 active 预设

## URL 模式

默认的 **包含** 方式匹配任何包含模式文本的 URL——此时 `*` 是普通字符。想用 `*` 占位请选 **通配符**；除以 `*` 开头/结尾外，模式两端锚定。

| 模式 | 匹配方式 | 匹配示例 |
|---|---|---|
| `api.example.com` | 包含（默认） | 任何包含 `api.example.com` 的 URL |
| `*://api.example.com/*` | 通配符 | `https://api.example.com/v1/users` |
| `*login*` | 通配符 | 任何包含 `login` 的 URL |
| `https://api.example.com/users` | 精确 | 仅这个完全相同的接口 URL |
| `*` | 包含或通配符 | 全部请求 |

建议：

- 定向规则尽量写具体，避免误伤其他接口
- 从会话右键创建规则通常更准确，因为 AIProxy 会自动带入真实 URL、主机、路径和方法
- 多条规则可能同时匹配时，用优先级控制最终生效规则

## 从会话创建定向弱网规则

这是推荐的精准创建方式。

1. 打开 **会话**
2. 找到要模拟弱网的请求
3. 右键该请求
4. 点击 **Create 弱网模拟规则**
5. AIProxy 会跳转到 **弱网模拟** 页面，并自动生成规则草稿
6. 选择要使用的预设
7. 检查 URL / 方法 / 阶段 / 优先级
8. 点击 **Save 规则**

自动带入内容：

- 主机
- 路径
- 方法
- 完整 URL

适合场景：

- 只让登录接口变慢
- 只让图片下载变慢
- 只让某个 POST 请求丢包
- 只验证一个 GraphQL endpoint 的弱网表现

## 查看弱网是否生效

### 在会话中过滤

会话顶部提供 **Throttled / All 会话** 切换。

- **Throttled**：只显示已产生弱网模拟 Trace 的请求
- **All 会话**：显示全部请求

这个过滤适合快速确认哪些请求被弱网影响过。

### 在会话自动化中查看 Trace

点击某条会话后，打开右侧响应区域的 **自动化** 标签页。

如果该请求被弱网模拟影响，会看到 **弱网模拟** 区块。

Trace 会展示：

| 字段 | 说明 |
|---|---|
| 预设 | 使用的弱网预设 |
| 规则 | 如果由定向规则命中，会显示规则名称 |
| 阶段 | request 或 response |
| Outcome | applied 或 dropped |
| Delay | 本阶段增加的总延迟 |
| Latency | 固定延迟部分 |
| Transfer | 按上行 / 下行带宽计算出的传输延迟 |
| 消息体 | 参与计算的消息体大小 |
| Message | 丢包或异常说明 |

常见判断：

- `request / applied`：请求阶段已增加 latency 或 upload delay
- `response / applied`：响应阶段已增加 download delay
- `request / dropped`：请求被丢包模拟拦截，通常会返回超时类响应
- `response / dropped`：响应在传输中途被丢弃，客户端看到的是失败的响应

## 推荐工作流

### 快速整体弱网测试

1. 打开 **弱网模拟**
2. 在预设中选择 `Slow 3G`
3. 点击 **Apply** 做 15 分钟临时启用（或 **Save & Apply** 长期保持）
4. 回到应用执行测试流程
5. 在会话中观察慢请求和错误态
6. 测试结束后点击 **关闭弱网**

### 精准接口弱网测试

1. 先在 **会话** 中捕获目标接口
2. 右键请求，选择 **Create 弱网模拟规则**
3. 在弱网模拟页面选择合适预设
4. 检查 URL 模式和方法
5. 保存规则
6. 重新触发该接口
7. 打开会话的 **自动化** 标签确认 Trace

### 丢包恢复测试

1. 创建或选择一个带 Packet Loss 的预设
2. 建议先用定向规则只作用于目标接口
3. 重新触发请求多次
4. 在会话中切到 **Throttled**
5. 打开自动化查看是否出现 `dropped`
6. 验证应用是否正确提示、重试或降级

## 工作原理

AIProxy 在代理管线中应用弱网模拟：

1. 请求进入代理后，先根据 Workspace 找到匹配的弱网模拟规则
2. 如果有规则命中，使用该规则指定的预设
3. 如果没有规则命中，使用当前全局 active 预设
4. 请求阶段：
   - 按 `packetLossRatio` 判断是否模拟丢包
   - 按 `latencyMs` 增加固定延迟
   - 按 request 消息体大小和 `uploadKbps` 计算上传延迟（上传消息体先缓冲，再按计算出的延迟交给上游）
5. 响应阶段：
   - 同样做丢包判定并增加固定延迟——两个阶段对称处理
   - 按 `downloadKbps` 交付响应，以约 16 KiB 的 chunk 渐进发送，下载逐步到达
6. 每次生效都会写入会话级弱网模拟 Trace

注意：上传侧是缓冲后延迟发送；下载侧按 chunk 渐进交付。它能较好地模拟“整体变慢”的体验，但暂不能完全模拟流式接口或大文件的逐块实时加载。

## 数据持久化

弱网模拟配置会保存到本地 SQLite 数据库：

- `throttle_profiles`：保存全局 / 可复用预设
- `throttle_rules`：保存定向规则
- `throttle_runs`：保存每条会话的弱网模拟 Trace

应用重启后，预设和规则会自动恢复。

## 常见问题

### Q: 弱网模拟和 API Rate Limit 是一回事吗？

不是。当前弱网模拟是弱网模拟，用来改变请求 / 响应链路的延迟、带宽和丢包表现。它不会实现 QPS 配额、API 密钥限额、`Retry-After` 或 `429 Too Many Requests`。

### Q: 为什么我保存了预设，但请求没有变慢？

检查以下几点：

1. 预设是否已点击 **Apply** 或 **Save & Apply**
2. 是否有定向规则命中并覆盖了全局预设
3. 请求是否真的经过 AIProxy 代理
4. 如果只设置了 Upload，但请求体很小，体感可能不明显
5. 打开会话的 **自动化** 标签，确认是否有弱网模拟 Trace

### Q: 为什么只想影响一个接口，却所有请求都变慢了？

你可能启用了全局预设。请点击顶部 **关闭弱网**，然后创建定向规则，只匹配目标 URL / 方法。

### Q: 多条规则同时命中时谁生效？

优先级数字最大的规则生效。建议为更具体的规则设置更高优先级，例如：

- `POST /login`：优先级 `200`
- `api.example.com/*`：优先级 `100`

### Q: Packet Loss 设置为 10%，为什么不是每 10 次必定失败 1 次？

Packet Loss 是按请求独立随机判断。`10%` 表示每次请求都有 10% 概率被模拟丢包，不保证固定间隔失败。

### Q: WebSocket 会被弱网模拟影响吗？

当前 HTTP / HTTPS 请求链路会应用弱网模拟。WebSocket 握手请求可能受 HTTP 阶段影响，但消息级限速、逐帧延迟和 WebSocket 丢包不是当前版本能力。

### Q: 如何确认请求是被弱网模拟丢弃的？

打开该会话的 **自动化** 标签，查看弱网模拟 Trace。如果 `Outcome` 是 `dropped`，并且 Message 显示被 active throttle profile 丢弃，就说明这是弱网丢包模拟造成的。

### Q: 15 分钟临时启用到期后会怎样？

到期后 AIProxy 会停用当前生效的预设。由于定向规则借用预设生效，它们也会一并暂停——规则只有在其引用的预设处于启用状态时才会起作用。重新 Apply（或启用）某个预设即可恢复弱网。
