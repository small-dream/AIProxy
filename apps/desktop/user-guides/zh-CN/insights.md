# 洞察（Insights）使用指南

Insights 把你抓到的会话聚合成统计指标，帮你快速看清整体流量健康状况：哪个域名请求最多、错误率多少、P95 延迟有多高、哪些请求最慢或最大。

## 数据来源

Insights 的数据来自当前工作区里**已捕获的 Sessions**，不引入额外配置：

- **正在抓包时**：基于最新会话前端实时聚合（约 150ms 节流刷新），数字会随流量跳动
- **抓包稳定后**：切换为后端持久化的聚合结果（约 5 秒防抖），避免重复计算

所以 Insights 反映的就是你在 [Sessions](./sessions.md) 里看到的那批请求。

## 入口位置

1. 在左侧导航栏点击 **洞察（Insights）**

## 概览卡片

页面顶部的概览卡片给出整体指标：

| 指标 | 含义 |
|---|---|
| 总请求数 | 捕获到的请求总数 |
| 错误率 | 4xx / 5xx 请求占比 |
| 平均耗时 | 所有请求的平均响应时间 |
| P95 耗时 | 95 分位响应时间（长尾更真实的体感） |
| 总流量 | 请求 / 响应字节总和 |

## 按 Host 统计

核心是一张按域名的统计表：

| 列 | 含义 |
|---|---|
| Host | 域名 |
| Requests | 请求数 |
| Errors | 错误数（状态码 ≥ 400） |
| Avg Duration | 平均耗时 |
| P95 Duration | 该域名的 P95 耗时 |
| Traffic | 流量大小 |

- **点击某行**：跳到 Sessions 页面并按该 Host 过滤，直接看明细
- **右键某行**：可把该 Host 设为精确过滤、加入排除、复制、或查看该 Host 的全部请求

## 分布与排行

- **状态码分布**：水平条形图，按各状态码数量降序
- **请求方法分布**：水平条形图，按 GET / POST / … 数量降序
- **请求排行**：可在「最慢请求」和「最大请求」之间切换，列表带状态码、大小、耗时的颜色强度标识
  - 默认显示 **Top 20**（无 Host 过滤时）
  - 当按某 Host 过滤时，展示该 Host 下所有匹配请求

列表使用虚拟滚动，大量请求也能流畅浏览。

## Host 过滤

顶部可对 Host 做筛选：

- **关键词**：Host 包含指定文本
- **精确匹配**：Host 等于指定值
- **排除**：Host 不等于指定值

激活的筛选条件以 Chip 形式展示，可一键清除全部过滤。也可以在统计表里右键某 Host 直接生成精确匹配 / 排除条件。

## 统计口径

百分位（P50 / P95 / P99）的计算方式：把所有请求耗时排序，取对应分位位置的值。Host 级别的 P95 只统计该 Host 的请求。错误数按状态码 ≥ 400 计算。

## 常见问题

### Q: Insights 能导出吗？

Insights 页面本身不提供导出。需要原始数据请到 Sessions 页面用 **导出 HAR**（可按全部 / 筛选 / Domain / 选中范围导出）。

### Q: 为什么数字会跳？

抓包时使用前端实时聚合，会随新请求动态更新；停止后切换为后端持久化结果，趋于稳定。这是预期行为。

### Q: P95 比平均耗时高很多正常吗？

正常。平均会被大量快请求拉低，P95 反映长尾，更能代表「慢的那部分」体验。排查慢请求看「最慢请求」排行。

### Q: 能只看某个域名的统计吗？

可以。用 Host 过滤（关键词 / 精确匹配），或在统计表右键某 Host 设为精确过滤，所有指标会相应更新。

### Q: 数据和 Sessions 对不上？

确认看的是同一个工作区和同一批会话。清空 Sessions 容器后，Insights 也会随之变空。
